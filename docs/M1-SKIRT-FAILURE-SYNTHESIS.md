# 裙失败根因收敛：停止逐点guide上的形状试错

本文件只解释既有试验的因果与下一步取舍，**不建立第二份能力状态表**。当前范围和是否通过仍以[CAPABILITIES的EQUIP-01](CAPABILITIES.md)为准。此次只读源码/历史报告/已保存图，不启动浏览器、Blender、物理或新参数搜索。

结论：当前裙实现能稳定给出某个受约束形状，但没有足够的材料/层次/时间信息自动决定自然坐姿褶皱。连续guide、换单个目标、切一条前缝都没有改变这一限制。下一次有意义的局部工作应改变**这一件裙的形状制作来源**，同时复用已开孔源和真实接触验收；不再在原逐点guide上累加补偿。

## 源码确认的共同限制

核对版本为原solver SHA `10a072d3ceecaeb798f5025c19387e7b7a65ee6ad1adf2f9fbb67507b6184e86`，不是17bd或失败box源。

1. `update(_dt)`每次从hips-local参考点重建全部particle；没有上帧速度、惯性或材料历史。先按腿弯角转点，再按两个大腿高度的最大值改Y。相邻点位于`lateral < radius*1.1`两侧时支撑分支不同。连续化该分支已试过，只消除一个数学阶跃，不能补足形状模型。
2. 源SkinnedMesh只是提供参考点/骨绑定。最终显示Mesh删掉skinIndex/skinWeight，由hips与大腿逐点guide重写；原裙六个前/后/侧辅助骨及其细致权重**不直接决定最终显示褶皱**。继续改善源权重本身，不保证改变当前显示裙；box的权重预算失败属于生产源转移风险，不是当时站姿渲染突变的解释。
3. 当前碰撞只认识两条实测大腿胶囊和家具OBB。它没有真实躯干、上衣内外层、裙自碰撞，也没有明确的“身体→裙→上衣”层次。测试器可以看见真实body/top交叉，不代表solver有能力修这些交叉。
4. 61点固定带包括原封口。固定点不被碰撞/边校正移动；需要同时保持内部cap与身体不相交时，本身就是不相容条件。已开孔源消除了这类矛盾，但其余上衣侧面层次和真实薄间隙仍需单独处理，不能把开孔当完整修复。
5. 八轮约束只在边长大于rest×1.25时拉回。短边压塌、面积变零、面翻转、二面角/褶痕、静摩擦与折叠层序没有对应约束。相同边长可以形成很多不同折法，碰撞+单向拉伸没有依据选择自然的那一个。
6. 最后一次边回拉后没有再次保证接触，1.25仍是软目标；当前实测最大边比可超过3。三角顶点/边中点/重心投影也不是连续面碰撞。源拆点法线和狭长褶面会放大明暗，但轮廓尖角不能靠改法线消除。

以上是源码事实。推论是：它**可以偶然产生可接受静姿，但不能作为“精细裙自然坐起”的通用生产保证**。并非证明世界上所有姿态引导都不可行；这里缺少的正是决定折法、层序及时间连续性的输入。换一个版型仍被同一重建规则驱动，不能合理预期自动脱离这些限制。

## 最多两个下一步选项

**建议优先A；两者都不在本任务制作。** 不需要用户理解solver，最终只需看同样的正常速片决定观感与范围。技术失败门仍需保留，不能为了给用户选项把失败当完成。

### A. 原制服保留：一次真正的离线服装制作闭环，替换本裙坐姿形状来源

复用现成开腰/开上衣封口GLB和已native确认的静态fit，不再切一次孔、不再换cage参数。先处理目前只有0.466mm真实身体间隙的源层次：在**衣服源**中明确裙在上衣内的穿着关系及实际厚度，为制作求解留可验证空间；不改身体、动作或碰撞半径。由一件裙的Blender作者场景输出完整坐下→坐稳→起身的实际表面序列，再选一个受限的姿态/阶段导出形式。运行时坐姿不能再把已制作好的折形送回旧逐点guide压平；只换这一件裙的展示adapter，经营/控制器不重写。

这不是再做15个控制点目标。唯一新变量应是**可行的服装层序/间隙与最终渲染表面制作**，随后采用已有原生cloth/编辑工具；不同时调十种刚度。原生cloth已经失败，故先用原失败frame1–3作便宜反例：静态实际body/top+self和保留pin可行后，第三帧仍失败即停止，不继续烘焙长片。若这道门过，再做同一完整9秒坐起，检查最终render面而非只看sim cage；导出/回读后，正常1×room/close及全过程最终手接触重算，另验进入/取消/反向起身和非坐姿边界。

成本：中高，包含一件衣服源层次编辑、离线作者运行与局部adapter；比原运行时迭代便宜，但不是“再花几秒调参数”。不承诺布料稳定，也不承诺一次烘焙可覆盖任意椅、腿分开或舞蹈。产品需观看决定：保留当前细褶制服，并接受首个可用范围严格限定在当前体型与动作，是否值得这笔制作成本。若完整真实折形仍做不出来，停止，不建设批量生成平台。

### B. 改为更适合源骨架的少褶裙款：保留真实蒙皮，不经旧逐点guide

不是继续当前box前缝。选择/制作一件**独立、少褶、明确层序的裙款**，复用现有六个裙辅助骨与权重制作规范，以真正SkinnedMesh作为最终显示；在源文件里制作该裙的有限动作响应，并通过现有角色语义骨/动作入口加载。只改装备表现层，仍不改人体控制器。目标是把形变简化到源骨架能稳定表达的范围，而不是宣称获得物理自然布料。

最小验证先只做站姿、完整坐起及走跑的同角色一套；原权重/绑定/UV、身体完整性、实际body/top/椅接触和原细褶裙A/B均需保留。必须看抬腿、手臂经过裙边和取消过渡；若呈现新的硬壳摆动，即视觉拒绝。不能因为用了真实蒙皮就跳过这些检查，也不能把坐姿换装或隐藏裙子作为过渡。

成本：中等源资产工作加很小的装备adapter，但原六骨是否足够仍未验证；少褶并不自动解决腿/椅接触。产品需先看实际独立样板决定是否接受裙款/风格变化，不能由技术负责人把当前制服直接替换掉。若用户坚持原细褶风格，此路不选。

两者的共同前置都是使用已有正确开孔/层次成果、验证最终可见表面；共同禁止项是继续原guide上增加任意坐姿偏移、重跑相同失败cage、删除身体、缩动作幅度或以胶囊0代替实际接触。当前失败box/17bd源及影片原样保留，作为反例，不追加第七组控制点。
