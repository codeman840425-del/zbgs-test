当前只承诺已测平地代表房间：楼梯、斜坡、攀爬、独立跳跃/跳跃输入、蹲伏、爬行、游泳、双人舞/身体协作、动态移动家具、完整道具拿取放置、复杂围巾/披风、任意体型与任意衣服自动适配、高跟/厚底、完整音频口型/音乐系统、手机性能目标、真实多人服务器，均不在本次M1A交付。跑步源动作的小腾空与舞蹈验证中的小跳落地属于相应动作接触检查，不代表独立跳跃玩法。

冲刺素材即使存在，也不自动纳入常规跑步。先验证Jog常规跑；是否需要独立冲刺由实际玩法决定。年龄感暂按成年青年/成年成熟研究，不默认儿童、老年或极端体型连续变形已支持。

## 从用户路径反推的必查链

选择人物 → 修改可支持的外观 → 换装/佩饰/持物 → 站立/走路/跑步与重选目标 → 接近椅子/坐下/讲话 → 起身 → 舞蹈/中断 → 卸下物件 → 保存 → 关页重进。每一阶段只开放已实现步骤，未实现项明确显示为缺口，不能用调试按钮或静态预览证明整条路径已打通。

当前M1A只覆盖F的换装/走停/转向/坐起/短舞及部分中断；M1B补真实M和状态隔离；M1C按顺序补跑步、最小直播+麦克风/附件、少量舞蹈持续接入；M2/M3再做参数与组合。每个新增样件须记录构建、主体/装备/动作版本、程序结果、正常速度录像、视觉缺陷、目标设备/开发机区别、可重复源流程和远程备份。

维护规则：新增需求先映射此表，查源资产及真实调用后更新；新基模/装备/动作不会继承旧行的通过。出现回归立即降级状态并链接失败证据。正式技术规范定型须等M1A、M1B及M1C最小样件通过；用户视觉验收独立记录。此表不承诺全部组合穷举或无限兼容。
