# 有限五官几何制作方案

这是源制作方案，不是完整捏脸平台或已通过的外观能力。能力状态仍以 CAPABILITIES 为准。本轮首样只做原女性、原男性各嘴宽 ±4%；不修改身体、动作控制器、原资源或 public。

## 实测依据与首样

`evidence/facial-geometry-plan-v1/source-measurements.json` 记录精确原 VRM 身份和可复跑测量。女性 Face 缓冲 2055 点、56 表情，男性 2056 点、54 表情，不能跨性别复制点号。两者外唇真实皮肤孔边界均为 32 点，与口内材质的 32 对应点在 Basis 精确重合。嘴宽分别为 24.931 mm、40.800 mm；±4%对应总宽 ±0.997 mm、±1.632 mm。这是首个离散幅度，不是已经验收的连续滑块范围。

复用 `scripts/m1-variants` 与 `scripts/m2-male-face-v1` 的固定 Blender 4.5.9/VRM addon 4.10.5、保存重开/重复导出、原文件 hash 与身份检查。**不复用 jaw 的“所有 key 加同一 delta”规则**：嘴的宽度变化必须同时改变张嘴/笑容的横向表达幅度。

源选择来自 Face_SKIN 与 FaceMouth 共用的真实口缘，不以某个绝对高度或女性点号套男性。嘴内全部原几何与口缘使用同一横向仿射；口周皮肤按源网格到口缘的测地距离在固定 8 mm 过渡内平滑归零。所有权重只由 Basis 生成一次；不随表情重新选区。保留嘴内所有组件，不凭材质名猜测哪组是牙齿或舌头。眼、眉、头颈接缝和区域外点必须零变化。

对顶点 i 预先固定 `A_i=diag(1+s*w_i,1,1)`，中心 c 是源口缘横向中点。每个绝对形态 `q_i` 都变为 `c+A_i(q_i-c)`；导出 `Basis'=F_i(Basis)`，`delta'_k=A_i*delta_k`。这是每点固定仿射，因此与线性表情混合可交换，不是给 Basis 变形后继续使用旧幅度。口缘两侧复制完全相同的 w/中心；原表情存在的接缝残差也要记录，不以 Basis 重合代替全表情闭合。重新计算形态法线，由实际导出确认 POSITION/NORMAL 字段，不承诺导出器没有写出的 NORMAL。

## 后续参数边界（本轮不制作）

| 参数 | 源编辑域与配套 | 主要风险 |
|---|---|---|
| 眉高、眉距 | 独立 FaceBrow 几何加眉周皮肤平滑域；眉表情全部同映射 | 悬浮眉、眉毛穿皮、表情强度失真 |
| 眼高、眼距 | 虹膜/高光/眼白/眼线/睫毛/周围眼睑；左右眼骨 rest pivot 与绑定共同编辑 | 虹膜/高光绑定左右 FaceEye，眼白/眼线/睫毛却绑定 Head；只挪眼球或只改骨都会分离 |
| 眼宽 | 每侧眼孔/眼睑/眼白协同局部仿射，按实际球面决定虹膜是否随宽；全部眨眼 key | 闭眼漏白、眼线分离；不能把闭眼 delta 原样保留当成功 |
| 鼻高、鼻突出、鼻宽 | Face_SKIN 上独立鼻梁/鼻翼地标与平滑域；避免鼻根拉动眼角 | 没有独立鼻材质；需要实际源地标，不可按材质单选或宽矩形截脸 |
| 嘴高、嘴宽 | 外唇/嘴内全部配套，口周皮肤平滑过渡；全部口型与情绪表达 | 牙齿外露、嘴内裂缝、笑容角折；嘴高还改变道具目标 |

头部坐标必须按每个原源的对象矩阵转换。当前 Blender 源是 X 横向、Y 前、Z 上；glTF 是 Y 上。新骨 pivot 的方案需要重算真实 inverse bind 和 gaze 配置，不能只篡改 manifest 声称兼容。

## 有限样件的验证与依赖

本轮源门：原/新拓扑、UV、权重、骨与 Body 相等；实际 Basis 位移、所有 56/54 表情的 `delta'=A*delta`、全部口缘配对；眼眉/颈接缝/区域外保护；原/新各形态边长比、面积、翻面/退化及新增接缝。原已退化的脸层另报，不把它们充作新失败或从检查中偷偷删除。保存参数、源点对应、四份可编辑 blend、VRM、表达映射和独立原源重生成 hash。

之后才用真实渲染检查中性、笑容、aa/ee/oo、闭眼及混合表达；源码数值正确不能代替观看嘴角/牙齿。嘴宽首样保持嘴中心，不代表麦克风适配自动通过；嘴高/突出会改变说话目标，须重新核麦头距与指向。眼距/鼻变化会影响眼镜鼻托/镜片中心，须新 fit。新 SHA 下的发型、颜色 mask、服装、动作资源都按实际不变量显式登记，不能自动扩兼容；不在本轮修改运行时。
