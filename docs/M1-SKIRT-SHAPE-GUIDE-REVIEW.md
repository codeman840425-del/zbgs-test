# 裙前摆硬折：源几何核查与一个有界制作小样

本记录是离线诊断及制作输入准备，**没有生成合格替代形状，没有修改产品求解器或控制器**。当前能力状态仍只查 CAPABILITIES。本次未启动浏览器、Blender 或布料模拟；没有修改历史固定构建及证据。

## 对象与可复算结果

- 实际裙 `prototype/public/assets/m1/m1-uniform-skirt.glb`：SHA256 `065305626976c59b370d082baa6fd1e2aed8c262490e04e39543345170eb8d8d`。
- 当前 `m1-skirt.js`：SHA256 `10a072d3ceecaeb798f5025c19387e7b7a65ee6ad1adf2f9fbb67507b6184e86`。它仍是已接受的几何等价性能优化版。
- 历史实际图 `assets-source/forearm-collision-v2/screenshots/c9f074519f18-authored-180.png`：已查看，可见前摆不规则尖折和侧垂片。图属于 c9 固定版本，不是本次产生的效果。
- 复算：`python scripts/m1-assets/review-skirt-guide.py`。输入为既有 `experiments/skirt-offline-corrective/source-topology.json`，脚本先比对当前 GLB SHA，过期就失败，不自动重生成源。
- 输出：`assets-source/m1/shape-guide-review-v1/source-guide-report.json` 和 `front-region.json`。后者是可编辑区域/精确索引合同，**不含新 target 位置，不能当成导出服装**。

实际源有742个render顶点、381个位置焊接点、700面、1080边。唯一开放边界是60点下摆，原始下摆Y跨度29.645mm；其中33点属于本次定义的前半区（front权重≥0.5）。原素材不是平直下摆，不能把所有原有褶皱都算运行时新错误。三角最长边/对应高的比值中位2.851、P95为6.796、最大13.999；长瘦面和不均匀采样会使逐点投影更难产生平顺面，但这些数值本身不能证明哪一尖角的因果。

61点按当前 hips-local Y≥0.09 规则固定，包括旧审计确认的20面腰部封口fan（face0–19）。这是独立源拓扑缺陷；封口全在pin带，不应未经分层复现就把它称为前摆锯齿的直接原因。本小样保持现有pin集合，不顺手删除封口或改变腰带；开腰孔素材仍是另一个已留档、未采用的源修复。

281组同位置顶点在render层被拆开。用源坐标重算当前同款面积加权法线，组内最大法线夹角中位76.59°、P95为114.99°、最大144.00°。这说明硬明暗并不全来自坐姿碰撞；部分是原褶皱/拆点的结构表现。**不能盲目焊接全部法线**：会丢失有意的折褶。此指标是bind姿态计算，不是c9坐姿的GPU法线观测。

## 共同风险与尚未证实的因果

1. 坐姿前片并未采用原裙权重的坐姿表面：每帧从hips-local参考点重建，用每点原始Z生成front、原始X混合左右腿，再投到两条真实腿的表面。相邻点front差最大0.6525。腿面横向距离在1.1半径处硬开关，左右腿高度取max；褶皱顶/谷因此可能获得不同支撑分支。
2. 接触投影后只有拉伸软约束；没有压缩、三角翻转或材料弯折约束。点可在不触发过长边的情况下压成硬折。每帧重置guide也没有让前一帧自然连续的布料状态。
3. 最后一轮是边长回拉，未再次保证碰撞；1.25倍是软目标，不是最大边长保证。现有历史整段最大边比可超过3。不能凭该参数声称衣物不拉伸。
4. 原有褶皱拓扑+逐点guide/投影+拆分法线叠加，是可信的共同解释；目前没有c9同帧每阶段顶点输出，尚不能定量分摊三者。图中轮廓尖角是几何问题，单改材质或法线不能修轮廓。

这不是重新建议已失败的平滑方案。`M1-SKIRT-OPTIMIZATION.md` 中连续腿面guide视觉改善不足；碰撞位移弯曲平滑引入250/480行走、890/1680坐起安全包络穿入帧。`M1-SKIRT-CORRECTIVE-TRIAL.md` 中开腰源cloth、局部细分和规则ring cage都未通过站姿初段接触；规则cage第3帧真实render/body仍23对相交。不能换一个参数名称重跑这些方案，也不能以规则网格就推定解决。

## 最小可编辑替代：一件裙的一个坐姿前片target

建议验证**艺术制作的坐姿低频形状**，替代前片坐姿guide的形状输入，不再平滑碰撞位移，也不做新布料系统。范围只含同一女性、同一裙、现有代表椅、现有完整坐下→坐稳→起身；站立/行走形状必须逐点不变。后续能否用于旋转椅、舞蹈或体型变体仍需分别验证。

1. 在下次获得浏览器窗口时，捕获当前固定构建同一实际动作的站立、半坐、坐稳三组：原始人体/原裙/显示裙点、hips变换、腿轴/半径、椅localBox+matrixWorld、动作时钟和source SHA。保留完整身体、上衣、手与裙。旧ca72输入有旧前臂缺陷，不能冒充当前动作输入。
2. 以本次 `front-region.json` 的精确焊接/UV映射和零权重pin准备一个可编辑shape key。用左右侧边、膝上前缘及中线的少量控制曲线构造前片lap形状；建议5个横向×3个纵向控制点，控制点取上述实际表面坐标和安全余量，不能预填一个假定人体尺寸。前缘选真实33个前半下摆点；保持原面、UV、材质及位置拆点映射。低频表面与原有褶皱细节分存，避免把source折褶直接放大成控制曲线。
3. 输出原始basis与单一seated target及控制参数，记录坐姿hips-local坐标、pin零位移和每点delta。坐起按真实腿弯角连续混合target；入出端点delta=0。在隔离solver中**替换相应guide输入**，不是在旧guide/碰撞结果上再加一次target；现有真实腿/椅接触仍在最后验。不得改动作幅度、动作时长、身体可见性或腰pin。
4. 先只跑一轮同条件完整坐起，与原solver双栏正常1×正/侧对照。保存guide输入、接触后、最终输出三阶段点，以判断新形状是否在碰撞阶段又被折回。继续复用真实身体/上衣三角、椅OBB、手段接触及alpha过滤探针；记录材料边比、面翻转/自交、前缘离散曲率、接触改正最大值。前缘曲率降低只是辅助量，不能替代看全片。
5. 拒绝条件：接触更坏、固定腰位移、站/走改变、前摆只是被抬高遮挡、接触投影重新制造同样尖折，或正常镜头改善不足。拒绝即保存形状与报告停止，不追加无限控制点/投影轮数。

制作产物计划为隔离 `seated-front-v1.blend`、可读control JSON、可重复导出脚本和精确SHA target；当前仅完成region contract，未制作这些产物。因为没有当前固定同帧的实际表面输入，现在编造target会把新的坐姿偏移当作模型制作，不值得合入。主运行时、资源manifest、controller和能力清单均未改变。
