## 动作和接触职责

单一 Phaser 更新：墙钟毫秒换秒 → 最多 1/120 秒子步 → 路径位移 / 短步转身计划 → 源动作时间 / 标准化骨骼 → 脚 IK 和骨盆 → VRM 同步 raw 骨骼与附加骨 → 世界矩阵 → 新人体装备修正 → 渲染。源动作根位移不再次应用到人物世界位置。

鞋底标定只使用图元索引实际引用的顶点，不能把共享 POSITION 访问器的全身体顶点误算成鞋。坐姿从新人体参考姿势选取 187 个骨盆后下部表面点，在实际坐姿下求其与髋骨的距离（约 0.128 m）；代表椅面固定 0.47 m。装备厚度独立管理，坐姿换装时平滑改变间隙，不用旧人体 0.2 m 固定骨盆余量。

转身：旧 0.8 rad/s + 收步等待作为 `?turnLegacy` 同人体对照；新 `turn-policy.js` 规划短步，支撑鞋同时锁世界位置和朝向。0.18 s 的当前抬脚完成后才采用新的落脚方向；急停不把空中脚瞬间拉回。数值时长改善不是自然度通过，需完整视频。
