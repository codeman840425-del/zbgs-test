# 第一轮独立 QA（2026-11-14）

对象是新建 Phaser + Three/VRM 二次元样板，**不是原人物已修复**。角色为 pixiv 样例，动作实际使用 Quaternius CC0 库；见 `motion-source.md`。本报告区分源码与数值事实、实际画面观察和未验证内容。

## 实际运行证据

- `output/playwright/actual-avatar-inspection.json`：真实 Chrome 页面加载 VRM 后，遍历实际 SkinnedMesh/权重，采样 10 秒裙装舞蹈中的变形顶点与运行数据。
- `output/playwright/locomotion.json`：真实加载的 Phaser `CharacterStudio.simulate()` 在三种速度下执行同一多方向、转角及家具绕行路径。此项以固定 1/60 秒加速推进，是数值测试，不是实时帧性能测试。
- `output/playwright/ui/seat-contact-report.json`、`sit-contact-final.png`：另一岗位对真实 CPU 蒙皮后顶点与椅面、椅背 Box3 做独立检查。
- `output/playwright/arms/arms-validation.webm` 及侧视/正面连续阶段截图：复查肘部、坐起和舞蹈。录制时的候选早于最后裙裤装备位切换与小腿接触修正；仅作阶段证据，最终完整视频以主代理最终候选录制为准。
- 早期 `output/playwright/anime/complete-sequence.webm` 被开发服务器热更新中断，**不是完整通过的验收视频**，不得据此宣称两套全序列完成。

## 已确认数值

实际 VRM 加载了 13 个骨骼网格（含换装时隐藏的部件），共 24,951 个顶点，其中 13,825 个有多个正权重。运行时最大权重和误差 `4.47e-8`；舞蹈中采样顶点的最大网格局部位移约 `0.490 m`，证明动作确实驱动蒙皮顶点而非仅移动整张图片。Walk 实际有 53 条重定向轨道、周期约 1.333 秒；当前校准步幅约 1.205 米。

实际 raw 足骨与 normalized 足骨世界坐标最大差约 `2.87e-8 m`。这些结果证明步行支撑锚点及骨架传递一致，**不等于鞋底全部像素零滑动**，也不涵盖停止收脚或舞蹈足底接触。

坐稳后，独立岗位最后测得人物网格落在椅面/椅背实体盒内的顶点为 0；短裤底部比座面高约 3.45 mm。修正使用脚位前移，未修改椅子宽深来掩盖碰撞。顶点盒检测不等于完整三角面连续碰撞证明。

## 已修复并有回归检查的问题

- 程序手臂 IK 肘极向原为身体前方，造成反肘；改为后方/外侧，并通过真实侧视复查。正式走、站、坐、舞已改用成熟动作库；程序 IK 仅作必要末端校正。
- 起步复用任意旧步态相位会把初始落在身体下方的脚保持过久，出现约 7.7 cm 过伸；现在新的起步进入半支撑相位，连续行走不重复启动。
- 录制过程中发现起步混合姿态重置支撑锚点会发生约 17 cm 的脚位跳变；现保留原落地锚点，只渐变摆脚目标，实际三速度路径复测上述残差通过。
- 原地转身由双脚贴地旋转改为交替抬脚小步；合成骨架 360° 检查有真实抬脚帧，支撑锚点保持。该项最终实际视觉结果以最终视频为准。
- 坐姿臀/短裤穿椅面和小腿后侧穿前沿由真实变形顶点定位，先校准髋部体积高度，再前移踝目标，独立复测通过。

`node scripts/qa-motion.mjs` 对解析两骨 IK、三速度支撑、重复起停、肘向和转身进行合成骨架回归；`qa-locomotion.cjs` 对真实 VRM/Phaser 数值断言。前者不能替代后者或视觉验收。

## 本机观测性能

Chrome 157，1440×960 视口，10 秒裙装舞蹈末段观测：本地首载约 1.11 秒，平均帧间隔约 6.07 ms，P95 约 6.08 ms；JS 渲染提交平均约 0.395 ms，P95 约 0.5 ms。场景 130 次绘制、147,246 个三角面、33 张纹理、83 个几何，JS 已用堆约 93.4 MB。裙装求解器 816 顶点、120 Hz 固定子步、重力 9.81 m/s²。

这是开发机本地 Chrome 的一次观测，可能有其他窗口并行工作。帧间隔和 JS 提交耗时均不是 GPU 执行时间；未测独立 GPU 显存、移动端、用户目标设备、弱网首次加载或长时间内存泄漏，不能宣称性能已普遍达标。

## 观感与剩余边界

实际侧视已经看到肘部正常弯曲，CC0 动作具有源动画的髋肩及手臂变化；裙装现为重力约束求解，不是直接跟腿抬起的硬蒙皮裙。裤裙是同一装备位的替换，不是两件外装叠穿；身体几何仍保留。

衣裙尚无自碰撞和通用体型适配，不能由此样板批准批量衣库。舞蹈直接保留源脚轨，尚未做与步行相同的接触分段脚锁；停止收脚、脚掌滚动、长发与手臂接触仍须按完整画面判断。当前短舞蹈是否达到用户要求的所有动作幅度，应以最终实播判断，不能仅由 clip 名称推断。
