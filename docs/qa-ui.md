# 独立 UI / 场景流程核查

范围：`prototype/src/main.js` 的 Phaser 输入、路径、动作状态；不代替人物动画及服装视觉验收。独立浏览器会话 `appqa`，本地入口 `http://127.0.0.1:5173/`，2026-11-14 实际运行。实施期间其他代理持续修改动作与裙装，以下按测试时状态记录，不把旧截图称为最终版本。

## 已实际验证

- **人物近景按钮不触发地面行走**：点击后 `mode=idle`，`position=[-0.5,0,1.15]`，`distance=0`，`target=null`。
- **换装按钮不触发地面行走**：点击裙装后 `outfit=1`，位置、距离与目标仍为上述值。此前主代理发现的 UI 穿透已由 `pointerdown/pointerup` 检查真实事件目标必须为 Phaser canvas 修复。
- **暂停时切换动作**：暂停站立时动画 frame=11928；点击短舞蹈并等900ms，mode改为dance但frame仍=11928、位置不变；恢复后900ms frame=12077，开始舞蹈。暂停是冻结模拟，动作选择会排入当前状态。
- **坐下请求的实际路径**：从初始位置行走至 `[2.633006,0,1.050539]`（距指定座位点约1.7cm），实际累计路程3.13458m；清空target/path、渐转至facing=0后进入sit。`collision=false`。没有坐下后继续执行剩余路径。
- 控制台发现favicon.ico 404；未由这次检查宣称整个程序无错误。开发时HMR重新加载会重置场景，不能把重置当作动作通过。

## 椅座穿模的独立几何证据（修复前状态）

椅面尺寸宽0.55m、深0.50m、厚0.07m；世界范围x=[2.375,2.925]、z=[0.62325,1.12325]、y=[0.42114,0.49115]。椅背宽0.55m、高0.50m、厚0.07m，中心约 `[2.65,0.721145,0.65325]`。椅面上表面严格取动作模块seatHeight，椅中心按seatBack后移；没有删除家具或缩小家具遮掩。

在坐稳并暂停状态，逐顶点调用 `SkinnedMesh.getVertexPosition` 再乘 `matrixWorld` 后，落在上述实体椅面盒内的顶点数：Body_1=78、Body_2=74、Body_4=14。Body_2在座面XZ范围内最低y=0.424688，比椅面顶低约0.06646m。证明当时仍有实际网格穿板；骨骼脚锁误差接近0并不证明身体没有穿模。该结果已交给动作与素材岗位修正。

后续主代理已改进裙装，并要求main将椅座/椅背world Box3传给服装模块；main接入已完成。成熟重定向步态与裙装物理调整后的最终效果，需用新一轮完整录屏和几何采样验收。
