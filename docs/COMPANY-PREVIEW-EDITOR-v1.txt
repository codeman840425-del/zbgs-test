公司场景预览：布置与样件分区
2026-11-17，用户最新指示优先于此前“仅供观看、专业操作由 agent 完成”的入口限制。

本包缺口：之前目录虽有多款外观及 agent 操作接口，用户只能切样件场景，不能在当前公司直接选物品并布置；房间布局、设施测试及无关状态控制混在同一长栏中，妨碍验收。
本包复用已有 165 项资源、固定安装与功能合同、事务 prepare/load/commit、保存恢复及镜头。不制作新美术、不改变角色 M2、不修改角色控制器。线缆制作候选保留，尚未接入；顶部样件已交付证据保留，不再扩款或为近景精修。

入口与行为：
1 公司布置：房间布局、楼层/房间选择；点选真实设施或列表选择；只显示该物品的可替换外观、安装允许的位置/四向朝向和适用状态。普通家具点击移动；精确坐标作为折叠的补充入口。支持复制到指定位置、移除独立物品及选择所属整体。
2 添加设施：按现已接入分类选造型，选择地面、墙面、桌面或层板等安装位；只把选中物品添加到当前公司。缺宿主明确提示先放桌/柜架，不跳去一个演示房。每项继续接受原完整安装/占用/包络校验。
3 设施样件：独立的分类造型对照和测试布局。公司与样件切换保留本次会话内未保存布置，切换房间示例保留对应草稿；关闭浏览器仍以显式保存的完整方案恢复。
4 镜头操作放画面旁；保存/恢复/导入/导出集中在页首。旧专用控件暂为代码兼容保留在不可见且 inert 的内部区域，不作为用户流程，也不重复呈现。

外观替换：在当前实例执行 replace-resource，候选按已有 compareFacilityFunction 筛选。保身份、最终变换、状态与子物；功能/安装不兼容的资源不是可直接换的皮肤。实际资源加载失败保旧。样件进入不等于角色实际使用已验。
位置：沿现有四向旋转合同，不新增任意角度/缩放。墙面旋转由安装面决定，信息内容随宿主槽位；这些不能当作任意落地家具拖动。支持物件选承载面，桌上设备保桌面高度。工位必要部件不能单独移除或复制，选择所属整体操作。

最小验收：真实 UI 同房间四款沙发原位替换；添加另一设施、移动/旋转；真实点击拾取与点击目标移动；非法位置保场景及已保存数据；房间/样件及不同布局往返不丢本次编辑；保存后关闭整个浏览器重开一致；常用视口无遮挡，控件无重复身份。针对多安装目标另跑已有实资源的 CPU 合同检查。
尝试预算一次实现及有依据的缺陷修正；不以全目录/每造型重复同一矩阵代替进度。这里只声明这个入口包的证据，未完成分类仍属于 C1，C2/C3 和人类验收不因界面完成而自动通过。
