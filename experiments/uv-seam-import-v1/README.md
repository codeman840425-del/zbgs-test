# UV 分片导入的拓扑复验

在项目根目录运行 `python -B experiments/uv-seam-import-v1/verify.py`，需要 NumPy、SciPy。脚本运行十个单元测试，读取三份固定的实际身体资源，生成 [receipt.json](receipt.json)。

验证对象是单一蒙皮图元的几何派生。制作端若能提供原始面角与拆 UV 后面角的对应，导入器检查两个方向相反的边确实源自同一条原始内部边，并核对该解剖部位允许的原始关节、全部所传非 UV 属性以及顶点邻域。恢复原始索引时，UV 仍逐面角保存。正例使用原生男体、旧女体和旧男体的实际腿部三角，每份均在测试中刻意拆一次 UV。输入面的排列或骨骼索引空间改变时需要制作端提供相应映射。

反例使用完全相同的渲染缓冲，分别配上连续原始曲面与原本断开的两片。两例产生不同且正确的结果，说明仅按空间邻近和可闭壳性无法识别原始连接。

原生男体 `7586` 的既存踝部仍被拒绝。四对实际边的端点分别来自左右脚内的不同原始索引分量，UV 之外，位置、法线和权重也有差异。原始分量、端点编号及逐项差分均在报告中。此验证没有生成新的原生男性袜子。
