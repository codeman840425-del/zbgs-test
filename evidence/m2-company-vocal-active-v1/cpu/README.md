| [run-01.json](run-01.json) | `5c132423` | 退出 1。录音棚男签在女签退场后真实走到站位，仍因拾音门失败。 |

修复后两房女签在固定脚点双脚站稳后仍超出拾音上限，各实际退场 1.01 米才释放预约。两房男签接手后产生了实测元音权重和唇缝位置变化。活跃占用和接近中的任务可冷开恢复，篡改的存档被拒绝，争用、取消、超时、销毁、起身离开和换房均通过。租赁房原椅完成实际落座和起身。

从制作工程运行下列命令。对同一固定检出复跑时换一个未使用的回执文件名。

```powershell
node scripts/qa-company-vocal-active.mjs --runtime experiments/worktrees/standing-vocal-95adfb27 --commit 95adfb2788699077c8b2c1585f38e3c8a6053268 --output evidence/m2-company-vocal-active-v1/cpu/repeat.json
```

Node 使用 60 Hz 模拟时钟推进正式动作和任务，用 PNG 元数据代替 GPU 纹理绘制。嘴型由程序性元音权重驱动。本回执的范围是 CPU 几何、动作和占用，画面、实录音频和音乐同步另行验收。
