## 相同内容能省多少

- 同体内只有男图 2、3 的编码与解码内容相同，均为 8² 纯黑。图 2 接 emission 和若干 sphere 槽，图 3 是原先留下的单独 texture/image/view，无材质或 thumbnail 引用。若另作男体特有的剔除，仅减 340 B 全 mip。女性无重复图。跨体完全相同的六组是纯黑、默认法线、两张材质球、眼线及眉图。双人传输或运行时共享需独立登记，单个身体的纹理定义计数不随跨体相等而变化。
- 只有女性 2、5 和男性 1、2、3 整张图恒色，分别为黑色 `[0,0,0,255]` 和默认法线 `[127,127,255,255]`。其余每张图在 X、Y 两轴均有变化。1×1 可表示相同的恒定采样值，哪怕两边全做，单体静态收益也不足 1 KiB。7586 那张专属面法线为 `[128,128,255,255]`，是另一份源图。[7586 逐图审查](../m2-native-body-cost-v1/textures/README.md)
- 45 张源 PNG 只有 IHDR/IDAT/IEND，全部为 8 位 RGB/RGBA。单次按原模式、尺寸、PNG 压缩级别 9 在内存重编码，逐张全像素解码相等且载荷均变小。两体合计少 7,844,285 B 嵌入载荷。容器对齐、对外 GLB/VRM 新 SHA、HTTP 编码后实际收益与运行读回均待发布包验证。女性 15 个 image view 的起始偏移不是 4 的倍数，7586 旧 splice 的偏移限制不能直接移用。若选此包，须以真实 view 区间重打包，保全所有非图数据和 accessor 对齐，再核每一条 glTF/VRM0 引用、表情、缩略图与原有 fit。旧上衣 2:1 和 KTX2 的有损结果另有各自的输入及作用范围。[服装源端对照](../m2-source-outfit-release-v1/budget/next-mechanism.md) · [顾问压缩调研](../../docs/research/RESOURCE-COMPRESSION-GAME-PRACTICES-2026-11-16.html)

复算在项目根执行 `python -B evidence/m2-uniform-body-texture-intake-v1/audit.py --check`；省略 `--check` 将完整 JSON 写到标准输出。
