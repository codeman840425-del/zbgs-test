当前三个主要样件的原生覆盖及原生局部调色，每个部位最多选两种材质、各有 map/shadeMap，按四个克隆的静态上界计入。原生调色来源 PNG 在运行时用于像素对照，未上传为独立纹理。旧男装的布料候选复用原纹理。启动长裤与换入短裤分别出现在驻留和已选范围中。

总工的开发机运行记录显示三个样件加载后的纹理数扣除基线分别为 51、47、36，卸载后都回到基线 1；对应静态贴图对象估计为 48、40、28。Three.js R187 在渲染蒙皮时可能创建骨骼 DataTexture，在渲染 morph geometry 时创建浮点 DataArrayTexture，实际 WebGL 纹理还按 source 和采样配置缓存。上述机制解释静态贴图估计与渲染器计数的口径差异，逐项归因仍需单独观测。渲染器的对象计数本身也不提供 GPU 字节数。

同一独立检出上的现有五项 CPU 用例通过。本审查使用实际文件、源码和 CPU 命令，运行时取样来自 `evidence/m2-record-budget-runtime-v1/report.json`。普通电脑性能仍待测。
