# 在同一个角色上切换实际鞋底之前

固定源码 `ceb68a39712a17617085108c3261b18b1b106b6b` 的 31 个身体配置、52 套穿搭中，每具身体的所有衣服都搭配同一双鞋。为复现鞋底变化，在 CPU 内存中为 `source-male-ab9a-release-v1` 加入了比原鞋低 20 毫米的诊断鞋。读取了实际可见鞋网格、左右脚跟和前掌的取样对象，以及世界坐标下的最低点。原始输入与四份源码的摘要保存在[原始记录](transaction.json)。

切换提交后，角色外观已经换鞋，但四组接触点仍属于隐藏的原鞋。直立六帧后，两脚最低点均比地面低约 20 毫米。先换鞋再创建动作控制器能选中四组新点，但静止时鞋底仍低约 20 毫米。从第二套鞋直接冷启动还会因读取未加载的默认鞋网格而失败。取消切换、加载失败时原鞋均保留。此用例专门定位控制器和加载逻辑。独立生产的实际厚底鞋使用另一具已登记的 1K 男体，须在房间和恢复入口另行测量。
