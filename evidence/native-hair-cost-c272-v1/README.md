# Native HairSet001 development short cost sample

This evidence uses the immutable `c2721e32b6ed` build from `experiments/native-hair-release-v1/prototype/dist`, Chrome headless on the development machine, 1440×1000 CSS viewport, device scale factor 1, room camera, playback rate 1 and speed 1.05. The source body is `7586d3bc…`, and the independent hair resource is `cfa965e6…`. The temporary HTTP server and browser were closed after sampling.

The selected raw samples are listed in `summary.json`. Two valid walking windows used the existing longer `directions` route and recorded 48 quarter second behavior observations, all in `walk` mode. The original and independent seated windows each held `sitProgress > .999` before and after their six second sample. The original and independent samples came from separate browser batches, so these are development observations rather than a synchronized A/B benchmark. The first horizontal-route walk attempt is retained and explicitly rejected because it reached `idle` before its 12 second window ended. A second wrapper also retained a false arbitrary distance rejection. Its raw observations were recovered without rerunning and are used only after verifying every behavior observation stayed in `walk` mode.

The independent hair window measured about 0.2435 ms mean `appearance.updateDynamics` CPU time per render and 0.6688 ms mean `renderer.render` call time. The original walk window measured about 0.0007 ms and 0.5699 ms. The independent seated window measured about 0.2427 ms and 0.6344 ms. `renderer.render` time is CPU wall time around the call, never GPU time. The dynamics timer includes proxy synchronization, the official VRM spring manager and replacement material updates. Body, clothes and the original VRM spring solver were not separated.

Whole-room counters during independent hair samples were 142 draw calls, 120,458 triangles, 56 textures and 85 geometries. Original samples were about 140 calls, 87,258 triangles, 47 textures and 83 geometries. The loaded state reports the exact hair asset SHA, the official spring implementation, 59 joints, 22 colliders and 15 external frames. After selecting original hair, then disposing the appearance, native scenes were removed and texture/geometries returned to the observed original counts. This is one actor and one short run, so it does not establish long-duration release or ordinary-PC performance.

The machine was Windows 11 build 26100 with an AMD Ryzen 9 9950X3D and NVIDIA GeForce RTX 4090. Chrome reported WebKit WebGL with an unmasked NVIDIA ANGLE renderer. The 4090 is a development machine and cannot represent ordinary browser hardware. No video was recorded. No runtime, asset or build files were changed.

`qa-native-hair-cost.cjs` owns the sampling code. `summary.py` only reads retained raw files and creates the selected summary. Raw reports, rejected attempts and the exact script are preserved. The samples do not claim visual, contact, animation, universal hairstyle or production acceptance.
