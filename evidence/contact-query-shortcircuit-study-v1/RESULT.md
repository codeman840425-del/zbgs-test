# 旧半平面区间的按需计算：有界可行性分析

900efdf24c88 AABB候选因独立薄楔反例拒绝，保持冻结、不合入、不测性能。本次没有修改任何runtime/产品/旧候选，也没有GPU/浏览器或整机性能测量。唯一实现是本目录离线分析函数与统计，用于根代理决定是否制作下一候选。

## 方案及等价边界

原prepared interval已经缓存三角相关的7个常量；无需再引入几何包围盒或新几何margin。按原k=0,1,2半平面顺序，计算对应start[k]/end[k]、更新lo/hi后，立即执行**原有同一条件** `lo > hi + 1e-9`。若成立且所有后续算式保证有限，可提前return null。

有限算式下lo只经Math.max单调增、hi只经Math.min单调减；加固定1e-9也是单调运算。所以已经严格矛盾的区间不会被后续约束恢复。仍允许原来lo>hi但差≤1e-9的倒序短区间，不能替换成无容差的几何“无交”。原parallel delta<1e-12与start<-1e-9条件亦完全保留。

为了节省真正算式，可按需计算原start0/end0，再start1/end1，最后start2/end2。每个标量内部仍原除法/乘加/减法次序，不用倒数乘法、不重排乘加；全部nonnull都会计算完整且逐值相同。这里重排的是互不依赖的端点标量计算先后，不改变每个标量公式。

**非有限/溢出风险整调用回原函数。** 可预计算三角constants有限域guard，每条rail计算一次有限域guard。充分域取各原输入绝对值≤2^100且有限；原den<1e-12仍先返回null。域内相减≤2^101、乘积和≤2^202，除以至少1e-12后重心量<2^242，第三重心与delta<2^245，实际clip除法（abs(delta)≥1e-12）<2^285，远低于binary64溢出。因此后续不会生成NaN破坏单调性。该域是算术安全分支，不是新的接触容差；超域原函数全部执行。

有必要保留非有限fallback：旧算法中后续NaN可能把lo/hi变NaN，导致最终比较为false并返回含NaN的对象。不能在此之前提前null“修正”旧行为。离线反例验证完整回原路径，未把这类异常当新功能支持。

**当前调用合同限制：** 延迟计算若return null，out.start/end未计算的槽可能保留旧scratch值；原函数会先全部填写。这不是对任意外部调用者的全对象副作用等价。当前唯一产品调用是motion.railClearance，`if (!interval) continue`，不读取null路径的scratch；factory创建独立start/end数组。在制作实际候选时应保持此局部合同，不宣称通用可观测scratch全等。nonnull所有字段和null/非null返回值严格保留。
