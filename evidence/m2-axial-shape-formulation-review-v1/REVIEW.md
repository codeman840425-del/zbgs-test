# 连续轴向映射：独立数学与保护域审查

**判断：可作为一个有界新表示候选，但尚未构造或验证。** 当前源的固定眼与 neck 之间存在真实的 Y 间隔，足以定义一个不触及这两组端点的支持区；原请求本身也具有轴向可分离形式。直接连续 G 可以避免将非线性函数的采样强行解释为旧 tet 内的仿射变形。它不能修订旧失败，不能保证最终三角皮肤、表情或轮廓自动通过；本报告不批准形状运行。

## 1. 坐标、正确 Jacobian 与单射条件

输入世界/源坐标记为 `(X,Y,Z)`，固定 head 原点为 `H`，令 `x=X−Hx, y=Y−Hy, z=Z−Hz`。完整输出是：

```
G(X,Y,Z) = (Hx + s(y)x,
            Hy + y + d(y),
            Hz + z + h(y))

             [ s(y)   x s′(y)    0 ]
J_G        = [   0    1+d′(y)    0 ]
             [   0      h′(y)    1 ]

det J_G = s(y) [1+d′(y)]
```

这里 `d,h` 是**位移**，不是绝对 Y/Z 输出。若使用源坐标 Y 作为函数自变量，必须统一扣除 Hy；导数相同但断点身份不能混用。`h′`、`x s′` 不进入行列式，却影响剪切、奇异值和条件数；det 合格不表示低畸变或视觉合理。

足够而容易核查的条件是：在完整作用域上 `s(y)>0`、`f(y)=y+d(y)` 严格递增，且实际目标门 `s(y)f′(y)>.12` 成立。对本 C1 分段多项式，逐点 `f′>0` 是严格递增的充分条件；不以仅有单调节点值代替导数检查。若已证 `s>0` 与乘积 `>.12`，则也推出 `f′>0`。

理由很直接：相同输出 Y 先由严格递增 f 唯一确定源 y；给定 y，相同输出 X 由非零 s 唯一确定 x；输出 Z 随即唯一确定 z。若上下外段是 identity，则 `f(y)→±∞`，可在整个 R³ 写出逆映射 `y=f⁻¹(Y′−Hy), x=(X′−Hx)/s(y), z=Z′−Hz−h(y)`。在上述条件下它是全局单射（并在全空间上满射）的 C1 变换。仅验证正 determinant 的散点一般不够；这里的结论依赖此特殊三角可分离结构。

## 3. 有限支持与 C1 identity 拼接

在 L、U 两端必须同时满足：

```
s=1, d=0, h=0
s′=0, d′=0, h′=0
```

这保证 G 与 J 在边界上分别等于 identity 与单位矩阵。只放一个值正确的端点，不能保证导数为零。拟议的两侧常量平台可采用 `(frameLowY,L)` 与 `(U,frameHighY)` 两个区间，分别给相同的 `s=1,d=h=0`。PCHIP 对相邻零割线的斜率规则有助于实现零导数平台；实际接入时必须**直接从返回的系数核平台确实恒定、内侧一阶导数确实为零**，不只相信名称。官方具体实现/API/许可由并行工具研究核定，本报告未安装或调用插值器。

外段应显式 identity，不让默认三次外推负责保护。两侧平台和内侧连接点必须是合法、严格递增且不重复的 knot；若本源/其他源保护范围重叠或请求点越过边界，应报告不相容，不移动固定节点或悄悄改目标。

对 **d 而非绝对 f** 建 PCHIP 的作用：外段 `d=0` 是常量平台，可将 `d′=0`，从而 `f′=1`，直接对应 C1 identity。若对绝对 `f=y` 两个外段采样点插值，它们的割线斜率是 1；邻近内段的导数规则未必保持边界导数恰为 1。后者不是数学上不可用，但不能自动继承位移平台的论证。

关键限制：PCHIP 对 d 的保形/单调性质**不等于** `1+d′>0`，d 可以下降过快。即使 f 的节点有序，也不能据节点顺序推断 `s(1+d′)>.12`。对 s、d、h 分别插值不会自动产生满足全部形状/保护合同的联合结果。

## 4. 全段 determinant 下界：应验证系数，不用采样冒充证明

固定最终 knot 与实际返回的 Float64 分段系数，连同库版本/构造规则存档。若三条曲线断点不一致，先取断点并集并做精确的局部多项式换基；不要把不同局部原点的系数直接相乘。每个共同区间中 s 与 d 都至多三次，`1+d′` 至多二次，因此

```
q(y)=s(y)(1+d′(y))      degree ≤5
q′(y)                  degree ≤4
```

应检查全闭区间，及所有 knot 的两侧取值/导数；外段 q=1。`s>0` 的全段检查可同时作。以下两种是可解释的全段验证方式，不要求新的形状求解：

1. **多项式包络法**：把每段换到 `t∈[0,1]`，将实际存储系数视为精确二进制有理数，构成 q（不是只把浮点乘积后的多项式当精确 q）。转 Bernstein 系数，其最小/最大系数包围整段值。以精确有理或向外取整区间运算进行细分；若每个覆盖子区间的下界都严格大于 `3/25`，得到该存储系数定义的实多项式下界证据。对 s 同理用严格正下界。若有子区间无法在预设预算内分离阈值，标记未证/拒绝；不能用密采样补成通过。
2. **驻点法**：端点及区间内 q′ 的全部实根覆盖所有极小值候选。用可验证的实根隔离（例如有理 Sturm 计数配合区间隔离）证明根数完整，再用区间计算界定 q；重复根、根在端点、降阶/常数段均需处理。s 的候选驻点来自至多二次的 s′。普通 `roots`/伴随矩阵算出的近实根、较小残差和若干采样，不能单独保证近重根未漏或最小值未越门。

这里只给数学验收要求，**没有选择/实现新的通用根求解器**。最小工程实现应优先复用已核工具；若当前只有普通浮点根枚举，应诚实标成“全候选数值检查、非严格区间证明”，不能写成已认证连续下界。包络法的有限细分可以给保守证据，但近阈值时允许得不出结论。

还需区分两个浮点层级：

- 对已存储 Float64 系数作为精确二进制数所定义的**实多项式**，有理/向外区间计算可给可信下界；参考阈值可以明确取精确 `3/25`。
- 运行时 Horner/导数求值还会舍入，坐标相减/回加亦有误差。若要声称“实际浮点求值也始终 >.12”，需把求值顺序、局部坐标计算和舍入误差纳入向外界，并保留严格余量；可用标准浮点误差界，但不能只加一个随意 epsilon。没有此层分析时，应标为“存储系数的连续实函数下界已证；运行时浮点界未完全认证”，另保实际有限性和输出检查。

因此不应在恰好 `.120000…` 的近阈值结果上宣布成功。报告要列每段保守下界、证明方法、误差模型、余量与未证段；采样只作独立诊断，不承担全域证明。

## 5. 输出皮肤、表达及适用范围

即便连续 G 是全局单射，其作用于**整张连续源三角面**的像通常是弯曲面；仅映射三个顶点后重新连成平面三角，是另一张近似表面。后者仍需检查面积退化、翻面/交叉、完整实际 101 截面与接触。不能用连续 det 代替最终三角表面验收，也不能把旧 tet 的负/低 determinant 改标为通过。

表达处理应使用同一个 G：`P′=G(P)`，`D′=G(P+D)−G(P)`。这仅保证 base 和该完整表达端点对应；一般有

```
G(P)+t[G(P+D)−G(P)] ≠ G(P+tD),    0<t<1
```

多表达加权同时混合也存在相同问题。完整端点 fixed 并不自动证明所有组合/中间权重或闭眼动作安全。已有的严格表达/接触、闭眼/笑/口型、眼白覆盖和发根附着检查必须保留；必要的中间采样需沿原项目验收机制补齐。Float32 base 与 morph delta 的重建会进一步引入误差，不能只验 Float64 G。头骨/眼骨、蒙皮及动画与 G 一般不交换，源 rest-space 的合格不能直接外推所有动作；正常游戏链仍需实测，不能先移动 iris 骨来掩盖问题。

最终 normals/tangents 及 morph 属性也必须按实际烘焙表面处理；连续法向公式 J 的逆转置与输出平面三角法向并非完全相同，不以位置成功推定全部导出属性正确。

本候选仅适用于目前 jaw/cheek/chin 这类**按 head-local Y 变化的轴向缩放、纵向位移与前后位移**。它不能独立表达左右不对称、局部鼻翼/眼窝任意雕形、旋转、一般关节变形或所有人物目标。不同预设可复用同一公式/支持区规则/曲线构造与拒绝机制，不能逐最坏点手工补丁。真实 101 目标仍引用原 request；从目标构造曲线只是输入，实际截面才是验收。

本轮产物仅此报告，使用原数据只读范围统计；没有候选插值器实例、曲线系数、目标算术新样本、solver、导出或 runtime 修改。原女裙、舞、4196 与全部旧失败证据不变。
