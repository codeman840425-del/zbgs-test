# 收敛后的最小可执行路线：原源顶点guide + Qhull体积 + 原生SLIM

这是 `review.md` 接口风险之后的收敛决定，取代其“可能先写一般线性约束适配器”的实施分支。**不写SLIM约束求解器扩展；直接把原源顶点作为tet节点，以量化的近似顶点guide调用原生b/bc，最终仍验真实截面。** 没有安装、tet生成、形状求解或资产输出；下列数值仅是请求公式的只读算术。

## 已实测的目标桥接

两个性别的22源边均只涉及23个不同原顶点。原 `Head.fit()` 的jaw/cheek/chin公式可以不改参数地在这23个源顶点求**请求guide**。再按原边和t插值回202个材料点，与原始202目标比较：

| 原请求 | 最大XYZ坐标差 mm | 最大欧氏差 mm |
| --- | ---: | ---: |
| female-round-full | 0.654 | 0.654 |
| female-long-slender | 0.590 | 0.609 |
| female-square-athletic | 0.504 | 0.504 |
| female-soft-wide | 0.710 | 0.710 |
| male-wide-muscular | 0.929 | 0.929 |
| male-long-lean | 0.704 | 0.704 |
| male-round-stocky | 0.942 | 0.942 |
| male-angular-athletic | 0.623 | 0.623 |

脚本 `vertex_guide_readback.py` 另以同公式在原202点重算，与原记录逐坐标误差要求<1e-12m，避免另写错目标。没有最小二乘、自由拟合、调参或形状试验。记录仅含目标近似误差，不输出候选顶点/网格。最大0.942mm说明此桥接有可量化余量；若SLIM源顶点实际软约束误差最大为e，则这些材料点误差可由凸插值界定为≤0.942mm+e。**这仍不是101真实截面通过证明**，原2mm正式门完全不改。

## 为什么接口之后不会必然卡死

1. 使用已安装SciPy 1.18.1的 `scipy.spatial.Delaunay`，以源头部点云、23 guide原顶点、域内眼发保护点/表达端点、固定外框点构建外包**凸体积工作域**。这是周围空间的映射域，不是封闭人体实体，不要求先把VRM嘴眼/材质接缝焊成watertight人体。头域外保持identity，外框接续须实际检查，不能用求解后截断/回钉隐藏位移。源身份、节点与材质不改变。原头部必要点和全部端点均须覆盖，不能只围住23 guide。
2. Qhull保留的原guide顶点可直接作为SLIM `b`；对应公式目标是`bc`。域内保护点作为独立原节点进入同一接口、请求位置保持原值。相同源坐标先精确去重并保存完整原索引多对一映射；同坐标出现不同要求时先报冲突，不能取平均。这里没有任意嵌入约束，也没有自写形变场。
3. `Delaunay` 不保证每个输入点都进入simplex，必须核实际 `simplices` 引用集合和 `coplanar`。23 guide/全部要求位置保持的控制点若缺失，前置失败；禁止用QJ扰动后声称源点身份不变。其他非控制点可用已核barycentric嵌入回读，但不能把控制点静默改成近邻控制。全部tet须有限、非退化、统一正向；极薄单元带来的数值病态仍是风险，Delaunay不保证适合SLIM的质量。
4. 未成为控制点的原base/morph点沿同一体积映射求值，导出仍用原拓扑及 `G(P+D)-G(P)`。即使源顶点为tet节点，原输出三角也未必是tet边界面，因此tet局部正向不能担保原面三角无自交，仍做原det/strict/实际截面检查。保持所有源skin权重、IBM、UV、材质、表达绑定与图片字节；目标源点guide不改变skin权重。
5. SLIM b/bc原生仍是软约束：保护点与外框实际误差必须≤原2µm，不能把soft_p叫成硬固定。不在求解后强行回钉。当前不能保证单一固定soft_p兼顾该精度和形变；失败就保留方法失败，而非现场换自写硬约束器。单tet API smoke与尺度检查负责选择一次固定设置，禁止对角色扫soft_p。

## 下一个实际工作包

**只先做 male 源的 target-contract、一次Delaunay域构建、全部点覆盖/identity/仿射读回。** 共用原20mm外域余量；固定一个点云选取与精确去重规则。记录原坐标及源属性SHA、tet拓扑、coplanar、guide/保护点对应、最小体积/条件数分布、全部端点identity≤2µm与仿射重建误差。仿射预检只是嵌入数学验算，不是新角色，也不把移动保护点的仿射测试作为正式准入。

沿原窄试验600秒/3GiB上限；不为质量/覆盖扫描点密度或Qhull选项，仅允许一次明确的实现错误修正。没有有效原节点域或稳定回读就停止并给具体源点/单元证据。通过后才用**同一域、同一原生SLIM配置**各一次male-long-lean与male-round-stocky，保原参数；原det>.12、眼发≤2µm、全部neutral/单表达strict、101实际截面≤2mm均保持。不通过即保失败，不缩参数、不逐样补点。女性及其余原请求仍未验证，男女游戏、服装、恢复与普通电脑后续门不因此通过。

这个小包有明确价值，即使形状未成功：它可检验原顶点可作原生控制、全部表达嵌入可还原、同一体积是否有足够几何自由度，解决当前API接桥缺口；不再拿27环笼的失败作几何可行性的替身。

## 已收敛的域点集规则与只读成本测量

具体规则由 `domain_point_readback.py` 固定，读取实际primitive引用索引，不按accessor中存在与否猜语义：

1. 全部坐标以原float32 accessor转float64；表达端点为float64的P+D，不预先量化。`neckStartWorldY = 原neck关节Y - 0.005m`。必要查询集为所有Face_00_SKIN/FaceMouth/FaceBrow的base和全部表达端点，加Body_00_SKIN中Y≥neckStart的base和全部端点。必要查询集bbox每轴加原20mm外余量，固定该域；眼发不能扩大成新的任意域。
2. tet节点选**上述语义的base点**，不是所有非保护表达点；加域内全部眼/眼线/睫毛/头发的base及原表达端点，且全标位置保持；加域内Body_00_SKIN的Y≤neckStart的base/全部表达端点作为固定颈接口；再加8个bbox角点作为固定外框。原23guide端点均须真实存在且不得与固定节点坐标相同。其余必要表达点只是后续embedding查询，未删除也未减验收。
3. 只按三个float64坐标**精确相等**去重，保存所有原引用与语义标签；不按1µm、1nm或任何距离合并。不得改变保护点、静默过滤近重合、用QJ扰动、把遗漏控制点改nearest。邻距检查只描述病态风险。已发现没有23guide与固定节点精确重合，不代表附近存在足够形变余量。
4. 先用一套固定默认SciPy Delaunay配置，不扫选项。前置验所有guide/保护/颈/外框控制节点确实被simplex引用；任何缺失就失败。tet定向可统一交换两个索引（坐标不改），但零体积/非有限/数值秩亏单元不能静默删掉继续。记录每tet局部边矩阵奇异值/条件数分布和最坏单元；不能仅因全局bbox下的绝对体积很小就判坏，也不能以体积>0外推求解稳定。
5. 以实际原坐标查find_simplex及barycentric；任何必要点未覆盖、含非有限权重，或identity/固定仿射读回误差>原2µm即失败。精确节点应另检查对应，不能靠近邻误差掩盖漏节点。全源base/全部端点（含域外identity点）读回并保存；本次不调用SLIM。仿射矩阵、单位与固定输入摘要须在执行前钉住，防止用identity代替仿射。此预检不保证以后large-deformation可用。

实际只读计数如下，尚未生成任何tet：

| 性别 | 必要端点unique | 主体base节点 | 眼发保护unique | 颈接口unique | 合并后含8角节点 | 最小不同节点间距 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| female | 8288 | 1349 | 5125 | 86 | 6520 | 119.209nm |
| male | 8142 | 1335 | 4384 | 63 | 5742 | 1.863nm |

这两个源的全部眼发端点恰都在域内（outside=0）；域外identity规则仍保留，不能依赖偶然计数省略检查。女94个节点、男4个节点的最近不同点<1µm，**男已有1.863nm近重合，是Qhull丢点/薄tet的真实前置风险**，不允许用删点把它变成通过。只读统计约1.4秒，不是tet或求解耗时。预计此6千节点量级在CPU上值得单次预检；tet数、峰值内存与执行秒数必须实测，不能预报成功。维持600秒/3GiB硬上限，一次male域，失败如实返回确切遗漏节点/单元。全表达直接入tet原会约1.2万点，当前选择base+保护显著减少了无需控制的近重合，不减少需要回读的表达端点。
