# 单色原生虹膜源独审

源审通过，运行端待独审。本次只核 a18 原男、7586 完整皮肤男及 bbe 原生双虹膜绿 #4f7a4a，不以作者 pass 代替独立证据。`source-check.py` 从三个实际 GLB 解包所有139 accessor及所有非图片bufferView，比较JSON及每张嵌入PNG。

- a18→bbe：全部139 accessor的元数据和逐字节数据、节点/蒙皮/IBM/形态/表达/材质参数/纹理采样/扩展JSON完全相同。21张图仅虹膜image3与thumbnail18改变；其余19张编码字节相同。
- a18→7586：相同结构/数据也逐项相同，仅Body image11不同。7586原虹膜PNG与a18的9bdd32f2…精确相等。因此9ae7830f…绿图可供7586明确固定的虹膜纹理变体；不能把含旧Body遮罩的整份bbe当7586换入。
- image3只有材质1 `N00_000_00_EyeIris_00_EYE (Instance)` 的baseColor及MToon shadeMultiply共同消费。1024×512、UV0、identity transform、LINEAR/REPEAT；alphaMode=BLEND及其余MToon参数在三份文件中完全相同。运行切换必须同替base/shade并保原采样/参数。

已直接查看源/新实际PNG：棕→绿，双眼绘制外形、深色中心与纹理细节的空间布局保留，alpha逐像素精确相同。87840可见像素中85632的RGB改变，透明区RGB不变。2208个可见纯黑像素保持；源可见纯白为0，不能以空集相同论证高光全部不变。诊断暗区maxRGB≤32共17090像素，其中14882改色；中心(256,260)由[40,21,7,255]变[15,29,14,255]。原作者原生配色也改变暗中心和虹膜图内绘制亮斑RGB，不声称“所有瞳孔/高光像素不变”。此阈值/矩形ROI不冒充解剖分割。

独立EyeWhite与EyeHighlight材质、几何和其贴图全都相同；这与虹膜图内亮斑变色不是同一项。没有几何位移、眼白修改、alpha变化或表情语义变化的证据。PNG观看不等于游戏近景眼神/亮度验收。
