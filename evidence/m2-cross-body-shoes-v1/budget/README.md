每双厚底鞋增加 72 个侧壁三角，保留自己原鞋的嵌入贴图。男女各六根骨骼的逆绑定与对应身体、签名装备声明的最大差值均为零。选中模型按实际文件统计，包含源身体内的隐藏几何。真实绘制数量随动作和镜头而变。

男女分别使用自己的四份模型，跨角色相同模型文件数为零。两人共用七份动作数据和清单，合计 13,884,854 字节，在依赖并集中计一次。两份静态双人估算都落在现有临时同屏参考范围内。

独立厚底包实查 **38 文件，43,939,306 字节**。其中 23 个文件是双签依赖，另外 14 个文件共 2,776,585 字节，包括游戏入口、编译脚本、构建信息、两份签名及其索引。包清单本身 73,825 字节，SHA-256 为 `641d0327ab4613218c31f63da2a6ea8cc5e7d13be36ebec3f3e9ceba6d11e248`。逐件路径、SHA、签名 ID 和单人预算命令均在[预算回执](report.json)。

从项目根目录复算，命令将完整回执写到标准输出。

```powershell
python -X utf8 -B evidence/m2-cross-body-shoes-v1/budget/replay.py
```
