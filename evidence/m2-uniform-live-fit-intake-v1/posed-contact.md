# 1K 制服眼镜在站立和坐稳两姿的表面相交

四份浏览器捕获都使用原始眼镜。把目标专用的四环控制应用到同一时刻、同一头部姿态和镜架安装矩阵后，女性每姿的皮肤三角相交对数从 80 降到 0，男性从 84 降到 0。原发片上的几何相交增加。表中箭头左侧为实际原始镜架，右侧为离线应用候选控制的结果。每个单元按有限长度的非共面三角相交对计数。[原始姿态及坐标](../m2-uniform-live-fit-capture-v1/README.md) · [按镜架部件及皮肤分组的完整数值](posed-contact.json)

| 身体与姿态 | 采样皮肤三角 | Face 交对 | Body 交对 | 两侧镜腿与皮肤合计 | 发片交对 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 女性站立 | 2,917 | 40 → 0 | 40 → 0 | 80 → 0 | 22 → 78 |
| 女性坐稳 | 3,679 | 40 → 0 | 40 → 0 | 80 → 0 | 22 → 78 |
| 男性站立 | 2,717 | 36 → 0 | 48 → 0 | 84 → 0 | 32 → 80 |
| 男性坐稳 | 3,209 | 36 → 0 | 48 → 0 | 84 → 0 | 32 → 80 |

各姿态的左右镜框、鼻桥和两个铰链对 Face、Body、发片的交对均为 0。所有部件和表面的未决共面计数也为 0。Face 与 Body 的实际基色图 alpha 均为 255。两具身体的原发使用透明混合，基色图 alpha 范围均为 0–255；交对数无法决定耳侧被哪些可见发丝挡住。耳根是否承托镜腿、皮肤间隙、转头过程和正常速度下观感仍需分别观察。

复算时先用捕获矩阵的逆变换，将眼镜及皮肤的世界坐标还原到镜架局部。七个眼镜网格的原始顶点与源 GLB 在每轴 10⁻¹² 米内相符，三角索引逐个相同。镜腿按配置四环的源中心、旋转和目标中心变换，结果按正式加载器的 Float32 顶点精度写回。该坐标系下直接调用原诊断的有限线段算法，全部碰撞容差沿用原值。截取皮肤时只过滤所有顶点均低于头部 0.22 米的三角；四姿中两种镜架的最低顶点均至少高于这一截线 0.219 米。[原算法](../../scripts/m1-assets/qa-layer-rest-triangles.py) · [目标配置来源](../../assets-source/uniform-glasses-transfer-v1/generated/provenance.json)
