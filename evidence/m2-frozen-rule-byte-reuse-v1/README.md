# 普通游戏按需读取角色

固定游戏源码 `2e2a3dc9`，构建 `38d56c68898a`。两份检出的 555 个文件相同。角色、绑定、制服和签名均沿用旧版输入。首屏显示两人，第三人在另一组。旧版 `60e3934ddd8a` 首屏已下载第三人的 12,141,256 字节 VRM。人为让该次请求返回 503 后，两名本可显示的角色均未入场。新版首屏只读取身份记录，第三人的索引和 VRM 均为零次；选中第三人后才请求。请求失败时，原来两人的骨架实例、签名和装备保持。恢复资源再次点击可换人和切回。[旧版实测](old-demand/report.json) · [新版实测](new-demand/report.json)
