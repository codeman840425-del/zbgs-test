# 独立双角色消费入口审查

2026-11-17。已核对公开入口到角色恢复、实例挂接、共享动画及释放的源码调用，并对两份源码执行 Node 语法检查。七项批处理 CPU 回归全部通过。

| 修正处 | 修正后行为 |
| --- | --- |
| 记录回读 | 实例从加载记录派生候选下一修订，保留稳定身份、原创建时间、来源与输入记录的修订关系。实例绑定的摘要和修订继续指向加载记录。释放前后均检查实例状态，过期的异步回读会拒绝。四份实际输入已逐一核对清单 ID、摘要、派生修订和来源。 |
| 离场准备 | 在第一次异步等待前复制世界坐标。准备、恢复和挂接分别校验当前请求，底层角色使用独立根节点及骨架。旧请求的 release 只持有自身对象，删除槽位前还检查引用身份。 |
| 双实例边界 | 公共组入口先检查有序输入为一至两条，再撤回前组并释放旧实例。清单读取同时核对记录身份和摘要。 |
| 页面及时间 | pagehide 在初始加载前注册。实际离页撤销批次并释放角色、观察器、场景地面和渲染器。浏览器历史缓存恢复时保留实例，重置次级动态及首帧。使用 Phaser 提供的帧时间，前台单步上限 50 毫秒，后台间隔直接跳过。 |
| 镜头 | 根据总工要求将相机 Z 从 4.8 调至 3.5。 |

实例展示按共享 motion、avatar、世界矩阵、服装的次序更新。入口只展示两位角色，行为寻路仍由房间控制器承担。开发版的真实浏览器结果记录在 `evidence/m2-record-consumer-dev-v1`；本轮未使用 GPU。修改后实际取景、动画、后台恢复等浏览器行为以对应固定构建的集成结果为准。
