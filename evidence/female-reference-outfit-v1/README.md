# Female reference outfit candidate v1

This package records four independent candidate slots from the saved turnaround reference. It reuses immutable female source assets and adds a fixed-workbench runtime extension whose material recipes are applied transactionally. The package remains a candidate and is not runtime-admitted or visual-accepted.

- Inner top uses the admitted 1K female uniform-top fit as a cream material candidate.
- Outer uses the static female vest-layer source as a lavender material candidate. It is not a verified knit cardigan and exceeds the m2 technical texture budget at 2K.
- Pants uses the exact female training-pants source only as a taupe fallback. It ends at the knee, so the ankle-length straight-trouser requirement remains open.
- Shoes uses the exact female uniform-shoes source only as a beige fallback. It is flat, so the low-heel requirement remains open.

The runtime smoke check at `evidence/female-reference-outfit-v1/runtime-check/` loaded outfit index 8, applied all four pinned recipes, captured front and side views, and restored the original outfit. This proves the import and transaction path only. It does not prove the reference cardigan, ankle-length trouser, low-heel geometry, normal-speed motion, seated contact or ordinary-PC budget.

All per-slot recipe, manifest, fit, coverage, source-lock and license data are under `assets-source/female-reference-outfit-v1/<slot>/`.
