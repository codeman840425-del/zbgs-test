# 原生唇妆固定浏览器回读

源码 1b1d6189，固定构建 637b3f8bb4a3，开发机 Chrome 157。两份不同 FaceContour 角色均从各自已有的绿虹膜和暖肤记录进入。实际 UI 验证原肤、暖肤各自的原唇和原生 101 唇妆，共八组妆前妆后开闭口画面。每个角色子目录中 plain-left-lip-right 图片左侧为原唇，右侧为同姿态唇妆，均由原始整帧按实际蒙皮唇部范围裁切。原肤改变较轻，暖肤的淡色唇缘在放大对照中较明显。

八组画面中，唇部投影内每对改变 1,352 至 2,008 个像素。四个张口画面分别覆盖 4,249、4,278、4,243、4,263 个可见口内内部像素，妆前妆后全部相同。闭口无可测口内核心像素。FaceMouth 的实际 base 和 shade 贴图核对全部 alpha 和全部不透明 RGB，与原生输出一致；该材质同时包含牙齿与口腔，没有单独归因到牙面。服装、虹膜、肤色的其他材质与身体遮罩在同肤色切唇时保持一致。

部分画面在唇投影外有 0 至 16 个像素最多改变一个通道等级。同姿态不改造型的重复渲染对照也出现一级差异，但仅部分坐标重合。逐对数字和重合数量见 cpu-readback.json，完整材料与几何采样见 report.json。录像以 1× 播放讲话、表情和转镜，每人完整解码 182 帧，约 6.04 秒；抽帧在 normal-speed-frames.jpg。逐帧背景完全相等、普通电脑性能与人工审美不计为通过。

每个角色的 original-lip.json 和 warm-lip.json 为实际捕获的 v11 记录。原肤持唇切暖肤、撤妆回 v10、撤肤回原先贴图、分别关闭重开恢复均已验证；在真实 UI 切换与 v11 记录恢复两条路径分别阻断暖肤唇面 PNG，两次失败都保留此前主体与造型。网路恢复后两种 v11 记录均已成功冷开。executed-script.cjs 为实际运行的诊断脚本快照。
