# 作者尺度：线性刚度换算的独立验证

**确认原作者设置缺少线性刚度的长度尺度换算。** 这不是宣布所有裙子穿插/拉伸失败都由该项造成。未改裙源、产品、旧失败记录或准入门；只执行预先定义的三组无碰撞窄布条。

## 机制

官方 Blender v4.5.9 的 `SIM_mass_spring.cc` 391–415、475–476 行分别将张力/压缩/剪切的插值系数除以 `avg_spring_len + FLT_EPSILON`。`cloth.cc` 1605–1639 行从实际 rest 边计算平均长度；1085–1103 行的 `lin_stiffness` 来源于结构/剪切权重组。当前作者只有 pin 组，没有这些刚度组，不存在隐藏的权重尺度补偿。

在同拓扑、质量及时间下，令位置和重力都乘 S：rest 与 avg length 乘 S。保持线性输入系数不变时，有效 k 约除 S；在同样相对伸长下，绝对伸长乘 S，弹簧恢复力因此近似不变，而惯性与重力都需乘 S。原 scale10 设置不满足这一线性运动尺度关系。`implicit_blender.cc` 1793 行及 `implicit_eigen.cc` 的线性力公式均与这个推导一致。

需区分系数：

| 项目 | 同质量、同时间、位置/重力 ×S 的换算范围 |
|---|---|
| tension/compression/shear 输入值 | ×S，使除 avg length 后的有效 k 保持不变。一般启用刚度组时，base 与 max 两端都需同比换算，保留权重分布。 |
| `max_*` | RNA setter 会把 max 抬到至少 base；实测150/150/80组的 max 也为150/150/80。这只是数值上下限联动，不会在 geometry 放大而 base 不变时自动补偿。 |
| 线性弹簧 damping | 当前直接乘相对速度；同时间速度已 ×S，故此项保留数值，不随线性 stiffness 一起盲乘。三组实际5/5/5相同。 |
| ANGULAR bending | 另一路径：`k = bendingInterpolated * restlen * .1`，角度差本身不随尺度变；因此保持该输入就已使角力项 ×S，不能照线性系数再盲乘。三组均 .6。此竖直条并未独立加载显著弯曲，不以结果声称全部弯曲相似性通过。 |
| 硬 pin | 位移随输入尺度变，固定自由度约束；不是 soft goal stiffness。软目标若另启用，须按其独立公式审查。 |
| collision/self 距离 | 是长度，应随几何域换算，但需要先决定真实源厚度与允许间距；本实验全关闭，不替裙子选距离。 |
| air damping/风/压力 | 本实验 air=0、无风压，不能用本结果证明这些项已换算。原作者 air=2 的行为仍需独立考虑。 |

源码精确 URL/原字节 SHA 见 `source-references.json`。默认值联动记录以每组 `actualSettings` 为准；脚本没有手动设置 max，但 RNA 会随 base 上调。

## 实际三对照

Blender 4.5.9 LTS / build `8bf95cbd38d1`；3×9 顶点、相同16个四边面，归一化宽0.08m、高0.4m，顶行3点全pin；每顶点名义质量.15、quality8、30fps、61帧（0–2秒），全程保存归一化顶点。质量/阻尼/时间一致，物体scale均1，倍率直接写网格位置和重力。无碰撞、无自碰、无内弹簧/缝合弹簧，无参数搜索。

| 对照 | 2秒归一化平均列长 | 2秒 strain=(列长/0.4−1) | 全程相对 scale1 最大逐点差 |
|---|---:|---:|---:|
| scale1；张/压/剪15/15/8 | 0.400122306096m | 0.000305765240 | 0 |
| scale10；仍15/15/8 | 0.401221803481m | 0.003054508702 | 0.001361886714m |
| scale10；150/150/80 | 0.400122304189m | 0.000305760472 | 0.000000024131m |

未换算组的归一化 strain 约为参考的 **9.99倍**；换算组在全61帧内与参考的最大逐点差约 **0.0241µm**。三组 y 向出平面位移均为0，pin残差不超过0.0061µm。因此这是可复现的线性拉伸尺度效应，不是通过碰撞排除、调门槛或改变实际时间取得的结果。

此加载主要验证张力；压缩和剪切的换算依据来自源码同类除长度公式，并未各自执行独立加载试验。不将本条的低绝对 strain 当成实际裙子的布料品质。
