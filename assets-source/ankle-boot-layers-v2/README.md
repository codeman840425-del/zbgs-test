# 直筒长裤外搭 MRT 踝靴

本配方只处理 1K CC0 男体、MRT 男踝靴和原制服长裤这一组合。原站姿与坐姿的近景中，裤管中间露出多块棕色靴筒。本次保留原鞋与原裤，另存两件配套技术样件。[原站姿](../../evidence/m2-ankleboot-room-v1/room/ankleboot-standing.png) · [原坐姿](../../evidence/m2-ankleboot-room-v1/room/ankleboot-seated.png)

靴筒从踝关节向上渐变，在已有筒身中部截面起采用完整修正。对当前顶点的径向先找裸腿、卷边内外表面和长裤。以既有 44 条边界方向中最小可移动区间的一半作为双侧余量，即 2.991 mm。裤口按派生靴的实际表面单独适配，在裤三角上采样，并将靴的顶点和边中点反向投到对应裤面。线性规划在保持每个顶点高度、左右腿中线和相邻片连续的条件下，优先减少整体移动和相邻顶点的位移差。初次约束用整只鞋对局部裤面投影，误把鞋尖轮廓施加给裤腿内侧，导致中线无解；改成上述局部对应后首次生成本批两件。未做画面扫参。[固定配方](recipe.json) · [原始逐向净空](../../evidence/m2-footwear-author-intake-v1/cuff-envelope.json)

靴筒移动 236 个渲染顶点，最大 20.29 mm。左右各 1,091 个踝以下顶点以及各 222 个前掌关节及其前方的顶点位置逐字节一致。裤口移动 94 个渲染顶点，最大 52.20 mm，范围在模型 Y = 63.82–238.20 mm，所有顶点都保留原 Y。两件的 UV、面索引、权重、逆绑定和纹理均保持一致。改动区域未检出新增非相邻三角面自交或三角面法线翻过 90°。[两件与来源身份](generated/fit-report.json) · [保护区与面形回读](geometry-readback.json)

仍相交的 14 对集中在两块裤面，对应靴三角覆盖 Y = 66.60–135.14 mm。裸脚原有的中性交叉也在。裤口还要以固定站、走、坐、起画面核对，尤其是膝弯时的裤脚、靠内侧的两腿间隙和新增外扩量。此组合保留原鞋跟与前掌高度；接地结果仍由动作实测决定。

从完整工程根目录执行下列命令。复验使用 CPython 3.13.11、NumPy 2.4.2、SciPy 1.18.1。输入是已归档的原鞋、原裤、目标身体与净空回执，均由 SHA256 核对。第一次写入是原子目录发布，现有输出只做字节对照。

```powershell
python -X utf8 -B scripts/production/ankleboot_fit/fit_layers.py
python -X utf8 -B scripts/production/ankleboot_fit/fit_layers.py --check
```
