# 全段硬支撑 v5：位置可行，动作连续性失败，停止本候选

唯一固定问题覆盖原138–210整段。男女四轮实际鞋skin线性化均在固定预算内收敛，289个求解采样上的已确认支撑误差小于0.5µm、骨长/可达与保护flight保持；**但170→171左小腿局部旋转跳变121.65°/115.65°，严重超过45°门，必须拒收。** 不进游戏，不扩30秒，不改权重、节点或IK分支追加补丁。

当前包保留这一次失败的派生动作和全量数据，不能当已验资产安装。v3/v4与原输入不变。其结论是“该位置模型有可行解，当前姿态/目标表示不能给出合格连续动作”，不是“硬接触在数学上必然无解”。

## 原数据与统一动作采样

输入仍为原73个视频PTS、原片帧率与v4派生动作，未跑新检测。每个原72间隔预先统一四等分，得到289个**动作约束求解/导出时刻**；不是289个新视频帧或检测结果，不提升原片帧率，不沿失败处加节点。73原track times是新时间序列的精确子序列。派生时间记录在`rows`中，timebase1/96000的PTS是原时间有理数细分；`derivedInterpolationNotVideoFrame`明确区分新采样。

支撑事件完全沿用既有人工区间，右204–205前掌细化来自v4。未知区域只接受实际鞋非穿透/固定骨长reach，不增支撑标签。foot世界姿态来自v4，rootXZ/hips转体/上半身local轨保留。

141–144、207–210原flight保护施加于所有派生子点（不只8个原键）：root/踝修正0，腿/足保留v4插值状态。实际VRM已进一步比较这些区间62个密采样点：所有骨骼世界矩阵与原v4差0，不能只用QP/原键相同代替；有限样本仍不是对所有实数时刻的解析证明。

## 数学问题与一次固定运行

每个统一时刻有rootY与左右踝Y修正。已确认支撑踝Y由实际鞋选择区域的最低点硬确定为地面0（前掌用toe region、普通支撑用全鞋），不是目标罚项。未知踝Y受全鞋非穿透约束。root和踝之间受实际固定腿长的reach硬界，保留1mm全伸直裕量。修正幅度绝对上限20cm。

已固定的目标为三通道修正的二阶差平方和，加1e−8位移平方作数值正则。四次skin迭代只更新鞋形/IK造成的高度偏差，不改变问题权重、标签、节点和硬条件。使用现有SciPy sparse trust-constr（每次最多250迭代），没有安装新包。

全部男女八次QP均以gtol终止、线性约束违反0；四轮后实际289点支撑误差女性0.246µm、男性0.497µm，非flight全鞋最低女性−0.246µm、男性−0.012µm，固定骨长误差<1.1e−15m。报告里的优化值省略了固定变量常数，因此可为负，不是“平方目标负数”或错误放行。

这只证明该采样位置问题在给定假设下可行。局部IK方向、完整运行时插值和自然度不是由凸QP证明的。

`knee-cause-diagnosis.json`由独立标准库四元数插值/FK只读核算：原v4髋局部膝弯平面在170→171转93.58°/93.12°；本次逐时IK复制并投影该方向后转106.56°/104.83°。关键四分点的参考投影向量最小49.5/55.0mm，远离1e−10零向量保护；没有证据说这是除零、quat符号或精确反平行分支的实现错误。更深屈膝增大膝平面半径，把原本不稳定的方向变化放大。

根高下沉同样不能推给真人：最小曲率目标、很弱的位移正则与“只需腿可达”的假设，允许在两段固定flight之间形成很深的中间谷。当前位置模型没有给“尽量不改变根高”的足够优先级/范围先验，也没有在解内约束膝弯平面连续与关节角变化。是这次目标/表示设计不足，不是已证明所有硬支撑方案都不可行。

## 实际VRM与运行时插值复核：同样失败

无需GPU的实际VRMLoader/Mixer复核已经完成，位置对离线最大误差F0.848/M0.920µm，raw/normalized骨原点差0。脚世界朝向对原v4连续曲线最大差约0.00216°/0.00071°；两段flight的62密采样全骨矩阵差0。原PTS、转体和身份未被坐标错误替换。

但289个求解点的非穿透不能保证相邻local旋转/位置插值：721密采样在源170.6附近出现新鞋底负值，121采样runtime lift补偿后仍**−7.03/−7.77mm**。已确认支撑区间的密采样补偿前最大误差也达1.33/1.49mm，超出这次1mm硬门；runtime lift为+2.172/+1.428mm，又使部分支撑正偏移至2.173/1.428mm。`acceptance.json`保存全部known-support密采样和最坏时刻。没有扩大lift或改插值来遮盖失败。

初次核查使用未normalize的`Quaternion.setFromRotationMatrix`结果做角差，导致相同flight矩阵也报约0.03°差值；验证器已改为规范化四元数并额外直接核矩阵元素，结果矩阵差0。此为诊断计算修正，不涉及任何资源、求解器、阈值/节点或flight轨变化，细节见`verification-notes.json`。

## 需要改变的假设，未执行

若继续，必须改变“先求root/踝位置，再每时复制旧膝平面”的解法假设：膝弯平面的连续状态、关节角/角速度边界需进入全段共同可行条件；不能只在170→171最后抹一个局部补丁。rootY变化也需要明确的最小改变量优先级或有依据的幅度约束，不能让仅曲率最小化把中段压低15cm。原膝平面93°变化不是可靠人体先验，选择另一连续膝平面应明确标为未观测自由度的制作选择。

所有支撑与flight条件仍须一次共同准入，不准重新软化地面、不把失败点改未知、不删跳跃。真实根深度/质心/膝轴没有标定，目前不能声称精确真人力学重建。此处只提出缺失的建模条件，没有生成下一版本或扫新权重。
