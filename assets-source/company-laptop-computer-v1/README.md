# C1 laptop-computer collection

Four project-authored laptop appearances share the desk-surface contract and a 0.55 × 0.04 × 0.38 metre closed-installation envelope. Each GLB includes a visible `power-status` node, a `screen-surface`, hinge rails, and a visual rear USB/power endpoint. The package is static display geometry. Operating-system behavior, actual hinge animation, cable routing, and character use remain outside this C1 production task.

Build with `node scripts/company-platform/build-laptop-computer-collection.mjs` and run CPU readback checks with `node scripts/company-platform/qa-laptop-computer.mjs`.
