# 静态设施四款结构样件

编辑 designs.mjs 中的明确构件尺寸、位置和构造；它是可编辑源，不是导出后的缓存。统一制作描述随生成报告逐项展开。桌子、键盘、桌麦、绿植、挂画各四款，几何不同，配色不计独立款式。

在移交 source 根目录运行 `node scripts/company-platform/build-static-collection.mjs`，再运行 `node scripts/company-platform/build-library.mjs`。修改固定功能规格不属于纯外观替换；不兼容时保留原公司，生成新候选验证。

生成器逐款双次导出、真实GLTFLoader回读并检查座落/桌面/包络，实际替换及保存验证见对应固定构建的四款预览报告。没有角色使用验收结论。
