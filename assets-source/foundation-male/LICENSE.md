# Male candidate source and use conditions

This folder preserves the single audited `Base_Male.vrm` exported and published by **hecko**, attributed on the source page to **VRoid Project**. It is a third-party export, not an original `.vroid` project obtained from pixiv. `publisher-page.html` preserves the publisher's source/version statement and original download link.

- Publisher: https://opengameart.org/content/vroid-studio-cc0-models
- Original download: https://opengameart.org/sites/default/files/base_male.zip
- Publisher statement: the bases were exported from VRoid Studio beta 0.14.0 without export optimization.
- Official legacy New model conditions: https://vroid.pixiv.help/hc/en-us/articles/900000088126-New-model
- CC0 legal text: https://creativecommons.org/publicdomain/zero/1.0/legalcode.en
- Current Studio guidelines, which must not be conflated with the legacy asset: https://vroid.com/en/studio/guidelines

The original VRM metadata declares `CC0`, use by Everyone, and commercial use allowed. The official legacy New model page identifies the old model as CC0 and allows editing/use. These are the preserved provenance grounds for this candidate. The third-party export has not been compared vertex-for-vertex against a newly obtained official beta export. Embedded metadata alone is not treated as independent proof of rights.

Do not extend this legacy CC0 statement to current Studio presets, newly added clothing or third-party hair. Current Studio guidelines contain separate conditions for character creation/generation applications. This record is not a project-specific permission from pixiv for every possible future generation workflow.

The `.blend` is our reconstruction of an editable project from the preserved VRM. It retains its source asset conditions; it is not a recovery of the original `.vroid`. Preview renders are made from this candidate. Local audit/fetch scripts are project-authored workflow code, not part of VRoid Studio. Blender and VRM Addon retain their own software licenses; pinned tools are downloaded separately, not bundled here.

Full evidence and limitations: `docs/M1B-CANDIDATE.md` and `evidence/m1b-selection/manifest.json`. Checked 2026-11-14. No runtime integration or final model selection is implied.
