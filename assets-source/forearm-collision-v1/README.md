## 表示与来源

`female.json` / `male.json` 存语义、骨名、joint node、inverse bind、绑定肘腕、6个轴向半径节点、肘/腕端球、原primitive与实际面/点索引。t=0肘、t=1腕。半径节点线性插值形成分段圆锥管，再与两个端球取并集；不是把节点另连成几条检测线。`clearanceMargin=0` 表示没有偷偷把旧8mm间距写入真实尺寸，衣物额外厚度由接入端明确配置。

选择所有至少一顶点LowerArm权重>0.5的身体面，保留整张边界三角。每个轴向区间取相交源三角所有顶点的最大径向距离，邻区间最大值给节点；凸性保证这部分绑定源三角被保守包住。端球由端面外的精确裁剪多边形求最大距离，不漏掉肘后表面。独立验证对女性312面/侧、男性331面/侧各45个重心格点检查，绑定空间0外漏。这不是任意姿势下混合权重蒙皮的数学保证。

## 固定历史76–78帧对照

只读取 `capture-ca72ada827d2` 保存的真实skinned身体；与源完整primitive索引核对一致。原捕获没有肘腕矩阵，因此用66个纯LowerArm权重点恢复每帧刚体变换，最大残差0.144微米，完整结果在 `validation.json`。没有新采集或伪称重新播放当前控制器。

新代理只在真实冲突frame77检出两条固定腰边，frame76/78两边均在外。frame77旧5条12mm rails即使各加8mm径向保护，仍分别间隔2.273mm、5.075mm；新包络覆盖两处。更宽松的完整20mm胶囊已能覆盖第一条，但第二条仍在外0.463mm，说明既有离散方位遗漏，也有尺寸不足。旧算法实际使用方向投影，本对照只证明几何覆盖不足，**不等同完整旧 `railClearance` 重播**。

已知4个冲突面顶点在新包络内。扩大到每帧全部312个相关面、4680个面内样点：76/78均0外漏；77仍3点最多外漏 **0.204mm**，来自混合蒙皮边界。必须保留此失败边界，不把拟合代理说成完整实际skin保证。根代理接入后须在正常VRM更新后查实际前臂与衣物表面，并记录最终solve残差。

## 保守性与接入限制

整张边界三角让端帽包含部分上臂过渡：女性最远轴向约肘后40.0mm、男性约60.3mm。这使肘端球大于单纯前臂径向尺寸。绑定样点到包络边界的最大内余量女性24.42mm、男性37.30mm；它是包络内部余量，不是衣物穿入量。球对所有方向相同，可能造成多余抬肘/离身；**男性尤其不能仅凭本文件直接宣布可用动作通过**。若该保守代理导致避让过大，应细分真实肘段或按实际skin窄相检查，不能简单把端帽缩小后声称依旧完整覆盖。

手掌超出选中腕界的区域需要独立hand轮廓；此数据不覆盖整条上臂。碰撞可检出不代表存在IK可行解，也不证明跨帧扫掠安全。固定腰环与旧运行时投影裙面不同。男性没有同类历史姿态捕获，现只完成真实源尺寸/绑定覆盖检查，未完成男性动态验收。

## 复建

本机Python3.13.11 / numpy2.4.2；无需SciPy、Blender、浏览器。

```powershell
python -m pip install numpy==2.4.2
python scripts/m1-assets/build-forearm-collision-profile.py
python scripts/m1-assets/qa-forearm-collision-profile.py
```

生成只依赖仓库内两件VRM；历史验证另需保留的ca72捕获和 `source-arm-blocker.json`。连续两次源生成及验证字节相同，记录在 `reproducibility.json`。不可把历史捕获缺失时的验证跳过包装为通过。
