## 唯一规则与语义

- 固定三样本坐标中值，仅派生特征；原点、分数及PTS保持不变，首尾重复边界明确。速度使用真实source_seconds。
- 2D尺寸用本段双腿髋–膝–踝投影长中位数，实际761.769px；模型尺度独立用中位腿长0.723949模型单位，不当米。
- 图像“地面proxy”为全段左右脚跟/脚尖imageY的95分位2051.574px；模型proxy为两踝Y的95分位0.78537。两者都不是已测地面，且模型并非独立真值。
- image脚最低点高于proxy超过0.04投影腿长且模型踝高于proxy超过0.025模型腿长、原点min(visibility,presence)≥0.65，形成air候选；至少连续2帧。空中判定不要求脚静止。
- 脚尖近proxy、速度≤0.18腿长/秒，脚跟抬起或移动更快，且模型踝近proxy，形成forefoot-pivot候选。全脚支撑还要求跟/尖同时近proxy且均低速、模型踝低速；本次没有任何帧满足此flat条件。
- 踝的原2D与MB2D成对距离只用于检查解剖左右一致性；不确定时不输出有身份的支撑候选，不改原脚点名。脚尖枢转绝不等于固定全脚世界锚。
- 输出air/pivot证据强度分别封顶0.65/0.60，仅启发式强度，**不是概率、物理接触置信或已验known状态**。不足则unknown。通过规则的candidate和物理已知接触严格区分；本次没有获得可用于强约束的物理known标签。

完整参数见`fixed-rule.json`；所有73帧features、分数、左右关联状态、PTS见`contact-estimates.json`。

## 独立核验结果

| 全身输出 | 帧数 |
| --- | ---: |
| 双足腾空候选 | 16 |
| 至少一脚支撑候选 | 15 |
| 未定 | 42 |

双足腾空候选为139–146及203–210。与既有人工观察相比：

- 已明确观察的141–144、207–210八帧全部保留，没有把真实跳跃压成地面动作。
- 139/140/145/146/206属于观察的起落模糊区，保未知，不能报成正确。
- **203–205右脚显见支撑，规则却将双脚判腾空**，三帧明确不符。
- 逐脚还出现138右脚、155–164左脚的误腾空；后者原观察为前脚掌近地/脚跟抬起。不能把脚尖枢转简化成脚跟升高即腾空。
- 左脚4帧、右脚11帧输出forefoot-pivot候选，flat候选0；未知不能被当作“接触否”。

具体误判不靠降低可见性解决：155/160/164左脚min confidence约0.893/0.910/0.897。203右脚尖速度仅0.0145投影腿长/秒，但脚尖距全局proxy约0.0501腿长，规则仍判空中。两个预测器同意“高于proxy”不能证明鞋底离地；脚点并非鞋底，足姿、局部投影/深度和点预测误差在此没有分离。

实际查看`contact-validation-timeline.png`，红框保留上述逐脚不符，灰色保留未知。`independent-validation.json`有原估计/观察SHA与全部分类计数；人工观察本身仍是视觉假设，不是力板或真实3D接触标定，因此不报告泛化准确率。

## 可用性判断与缺口

**不足以驱动离线root高度、固定接触或逐脚IK约束。** 只能保留为可复跑诊断信号；禁止依据此结果每帧minfoot抬高、全程双脚锁或删去真实腾空。

缺口是随透视/脚姿变化的地面与鞋底接触定义、可区分前掌枢转/滑动/摆动的时间证据，以及原点和模型的相关预测误差。当前单一水平imageY下包络不能提供这些条件；后续若做其他方案，应先声明新增证据和地面/接触假设，而不是继续给此规则调阈值直到贴合13区间。本轮至此停止该规则试调，v1/v2和原数据均不变。
