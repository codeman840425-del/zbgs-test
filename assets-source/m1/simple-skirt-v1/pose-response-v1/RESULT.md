# 六骨响应第一次离线试验：作者目标自身失败，不接游戏

输入严格为固定 269 四姿与 v4 GLB `cdd2d206…`，没有更改源顶点、身体、控制器、动作、原默认裙或准入门。六私骨未装入新控制配置，17034 GPU 证据仍是原无坐姿响应版。

保留的 120 面/162 顶点对六辅助骨的总权重实际为 0。新下摆最大 helper 权重 .62，其余 hips 随髋，裸 LBS 的腿旋转无法等比抬起全部前片。

一次离线作者目标：前片按真实坐姿大腿方向连续旋转，后片留 hips 参考系，中间环按源高度/方位连续混合。**这只定义候选形状，不假设真实支持已经满足。** 对这个目标做六轮固定次数的六刚体交替最小二乘拟合，不在 runtime 逐帧优化。最终目标残差 RMS 11.038 mm、最大 38.249 mm；局部骨平移最大 177.256 mm，实际表面最大变化 157.515 mm。这些数值不是通过证据。

实际 body/top/chair BVH 显示目标自身不合理：

| 姿势/模式 | body pairs | top 非 cap | chair seat | self pairs |
|---|---:|---:|---:|---:|
| 六骨站立 | 0 | 185 | 0 | 1 |
| 六骨坐入 | 10 | 90 | 0 | 2 |
| 六骨坐稳 | 232 | 236 | 158 | 121 |
| 作者目标坐稳 | 287 | 123 | 168 | 111 |
| 六骨起身 | 0 | 98 | 0 | 0 |

不能用单 corrective 精确追随这个坏目标，更不能把拟合残差完全归结为六骨表达不够。站姿右腿本身有 .035 rad 前屈，按连续输入激活了少量响应（最大 .314 mm），故站姿数字不是原 v4 400/190 的重复门。未来响应必须明确站姿基准与非对称抬腿，不用动作名称强切。

## 已定位的支持区域

粗 hips-local 面质心分类（非外露/身体解剖真值）显示：坐稳作者目标的 body287 对涉及210个裙面，前部21、中带189、后部0；chair168 对涉及167个裙面，中带57、后部110。六骨结果分布相似。因此当前目标至少有两个独立欠缺：前/侧过渡带仍进入真实大腿根部；后片维持垂挂而经过真实座板。不是再增加一个统一旋转角就有支撑解。

`actual-body-seat-space.json` 保存真实身体/椅可用空间：21×21 seat-local 竖直射线145个有覆盖样点，最小间隙8.061 mm；另外将完整实际body三角裁到真实seat XZ矩形，再求线性Y在裁剪多边形的最小值，2166个有效面，最小竖直间隙 **6.163 mm**，无面跨seat plane。这个值针对当前坐稳姿势和真正座面足迹，不代表连续全动作的最小间距。输入旧手层不影响最小点（hips-local约[-.0914,-.1317,-.2499]，腿下侧），但保留全部面供复核。

源内折边 inset 为0.8 mm；它不是新设全衣厚度，也不能等同已允许布料接触容差。当前空间数值表明不必预设后片只能扩到座板外缘；下一作者形状应先检查在臀/腿下与座板间真实折回的可用空间。实际后片源长度、连续连接和整片碰撞仍待制作，不将这项可用空间诊断当目标通过。

当前方向冻结，不继续角度/位移拟合。上衣过渡由独立 `layer-transition-v1` 源修正负责。下一次作者响应须改用经 GPU 核对的层修复源，不能让这个 v4 配置跨 SHA 继承；先目标本身真实 body/top/chair/self/连缝门，再决定六骨与唯一 corrective 的必要性。
