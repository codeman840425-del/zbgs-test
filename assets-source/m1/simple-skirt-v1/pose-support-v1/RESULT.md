# 第二作者目标拒绝：停止弯曲管状坐标方向

唯一目标使用已修站姿层序源 `d7b5a881d1a64bdaf5e1d92a72573c2cef34abe859e53af0f9a2c8b091bd55fa` 与固定269实际坐稳 body/top/chair 输入。它不是游戏装备，没有制作 morph/inverse LBS 或改控制器。

目标把截面从腰下转向两腿，以源轴向布线中位长度242.902mm确定中心线/前伸距离，真实下半身体面为径向下界，已开上衣与实际椅面为上界。前伸沿大腿208.435mm，并未默认覆盖到膝。保留120原面/20边界以及第一下摆环，UV、身体、原源权重没改；只产生一个离线目标数组。

实际检查拒绝：4条射线没有可行区间；body766/top非cap233/椅0/self2。椅和自交计数比第一坏目标改善，身体却更差，不能包装成接触通过。真实材料也失败：源布线234–252mm，目标168–428mm；最大边比10.0507、面积比7.1092。代表边865–866从8.524mm拉到85.669mm，位于新下摆第5环，并非仅微小UV边的比例假象。完整面门与最坏边实际点在本目录。

共同原因：保持中心线弧长不等于保持每条布线/各三角的材料长度；统一转向的截面会让前后片需要不同长度。径向真实表面采样也会在腿轮廓交界处切换命中，邻点发生大幅分离；它没有材料边长/剪切/弯曲的联立约束。**这不是修一两个角度即可成立的作者形状。** 此方向冻结，不继续调curve/间隙，也不把逆解成morph当改进。

`geometry-gate.json` 使用完整实际body（包括当时旧手层），不删除身体/衣服；pair不是外露洞数。新目标还未进入运行时闭环，不能把旧手几何误作最终新手皮肤。后续方法评估见 `docs/SIMPLE-SKIRT-OFFLINE-AUTHORING-ADMISSION.md`，不自行展开新的仿真。
