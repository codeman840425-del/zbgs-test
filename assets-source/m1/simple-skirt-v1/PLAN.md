# 单一少褶裙替代：v4 源 checkpoint / 隔离诊断在制

基线aed9597独立worktree，初始源码摘要精确269a73423c97。原共享源码与原制服裙默认项不改。此处不是M1通过记录；能力仍见主工程CAPABILITIES。

## 可编辑源设计

原裙约20细褶改为6个宽浅褶、近似原裙长与深蓝配色的独立A字样件。采用真实渲染曲面120个周向分段、16个纵向层，腰/上臀加密，避免旧39–41mm接触面和中点细分产生的亚毫米短边。不是仿真cage回映到旧面；最终面直接进行接触验收。实际腰孔保持开放，真实内折裙边/内搭面保留，完整皮肤不删面。

初形源参数、显式UV、骨权重可重复导出GLB，随后保存含Armature、vertex groups、UV的Blend并回读。材质为程序参数，不引入图片授权或把旧褶纹贴成新褶。只有本装备使用新的权重，人体/动作/原裙不改。原六个裙辅助骨直接挂UpperLeg，脚本会保留原inverse bind并按真实空间扇区分配hips+相邻两个辅助骨，最多3影响；这是新作者权重，不冒充原权重无损转移。

姿态问题不在旧guide上补：先看实际蒙皮的四个姿势，必要的有限作者折形直接作为该装备shape输入，随真实大腿姿态选择且验证插值/取消；如果需要分节骨只能归该装备自有骨架，不改humanoid映射。当前尚未制作pose shapes，不得声称自然坐姿已有解。

## 准入及停止

先检测真实站、坐入中段、坐稳、起身中段的完整body/top/chair与最终可见三角，原裙同姿保留对照。静态源孔/非流形/权重和面质量先查；四姿不合格立即报告具体区域，不自动改间隙/放宽阈值。只在其通过后进行完整正常1×坐起、走跑、代表舞和取消，实际手fit重算；旧手面/胶囊计数不能代替新最终皮肤。

旧上衣有已经确认的内部封口。若候选采用已存在open-top，必须在独立组合中明确使用其独立SHA，不静默改原对照上衣；外露层次和内部cap分类分别保留。任何风格变化须看样板决定，不取代原默认装备。
