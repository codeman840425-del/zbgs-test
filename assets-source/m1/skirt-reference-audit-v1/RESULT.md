# Two-source bounded audit — 2026-11-15

The free Blender-chan source was actually downloaded and opened read-only with Blender 4.5.9, factory startup and autoexec disabled. It is an editable reference, not a verified seated skirt or a compatible replacement for our female VRM. A single native standing/seated pressure sample is now separately authorized; this report does not predeclare its outcome.

## Blender-chan / Amarillo

[Author and free source](https://amarilloarts.itch.io/blender-chan). Author states the free version is public domain; the separate Patreon version has different terms. We obtained only `BlenderChan - Free.blend`. No helper addon was installed or executed. No embedded Text datablocks were present. Original bytes and SHA are in manifest.json; the original is never overwritten.

The actual `Skirt` has 298 vertices / 266 polygons, no shape keys, no object/shape drivers. Its chain is Armature → CorrectiveSmooth → Subdivision → Solidify. Weights use waist, spine, buttocks and thigh/twist bones; no bone name contains skirt/dress. Main rig drivers are not evidence of garment seated correction. Available actions are mainly single poses, `Idle Dress` (0–1), and a one-channel turntable. The inventory establishes no explicit seated author example, not inability to sit.

The author's viewed full-body image shows a front-open petal silhouette over a leotard. Its body, topology and Auto-Rig Pro skeleton differ from our current female. Blender modifier results are not automatically preserved in glTF/Three; fitting, baking/export and actual target compatibility would still require validation. No style selection or character replacement is implied.

Read-only reproduction from this directory (Blender path supplied by operator):

```powershell
& $Blender --background --factory-startup --disable-autoexec ./BlenderChan-Free.blend --threads 2 --python-exit-code 1 --python ./inspect-blenderchan.py
```

Reacquire only if necessary: `node download-blenderchan.cjs`; it uses project Playwright or PLAYWRIGHT_DIR, no saved signed URLs. Verify downloaded SHA against manifest before use. A changed upstream file is a new version, not silently equivalent.

## MakeHuman frankyaye_mini_skirt_01

[Official skirts pack](https://static.makehumancommunity.org/assets/assetpacks/skirts01.html) identifies the selected asset as CC0. Its downloaded `.mhclo` header says AGPL3. This may be a historical generator header, but no evidence resolves it; the asset is not admitted under a guessed license. The selected directory is OBJ, `.mhclo`, `.mhmat` and textures, without a rig, seated animation or corrective target. `hm08` barycentric correspondence indices do not map to our VRM.

Official primary transfer stalled and was cancelled; the official files.makehumancommunity.org mirror completed. The individual historical node page had a certificate mismatch; verification was not bypassed. Archive, selected source and hashes remain local; conflicted source and ancillary web images are deliberately not redistributed in Git. No other pack assets were investigated.

## Boundary

Only these two sources were examined. Neither is currently an established seated replacement. Blender-chan is the sole licensed editable reference retained for the authorized native pressure sample. No source fitting, controller changes, original-body hiding, new library, purchase or third-party contact occurred.
