# 事件节点 + 硬支撑：只读方法决定

建议下一候选改变两项已知不适当假设：**软支撑允许悬空**、**所有脚姿都保持水平**。采用既有人工支撑/腾空事件定义节点、明确接触面的硬几何约束，并开放前掌蹬地所需的足部俯仰；不建议只把v3支撑权重加大或只强迫root下降。未生成v4、未扫参数、未修改v3或原检测。

本结论有单姿态几何证据，但不是整段可行或自然度证明。`feasibility.json`保存计算、公式条件、输入SHA。脚本`assess-dance-event-constraints.py`只读现有数据并写诊断，未导出动作轨。

## 205→207 平足方案的必要代价

205右单脚支撑、左摆动；206起跳时刻模糊；207–210双足可见腾空。205→207原PTS间隔83.4167ms。保持当前踝XZ、水平足姿与固定骨长，使205右足接地的必要root下降为F32.636/M36.010mm（全伸直极限，尚未加膝弯裕量）。保持207原flight根高时：

| 量与条件 | 女性 | 男性 |
| --- | ---: | ---: |
| 额外根修正平均回升速度下界 | .391m/s | .432m/s |
| 加原target根运动后，根平均上升速度下界 | .602m/s | .664m/s |
| 原target205→207平均上升速度 | .211m/s | .233m/s |
| 修正接207时速度为0：修正峰值绝对加速度下界 | 9.38m/s² | 10.35m/s² |
| 再额外要求205修正速度也为0：上述下界 | 18.76m/s² | 20.70m/s² |
| 示例两端零速度cubic：修正峰值加速度 | 28.14m/s² | 31.05m/s² |

公式：位移D、时间T的平均速度为D/T；末端修正速度0时，`max|a| ≥ 2D/T²`。两端速度0时`max|a| ≥ 4D/T²`；三次smoothstep的峰值为`6D/T²`。**205修正速度0不是支撑的必然条件**，所以后两行只是更强边界的代价，不能称普遍必要。若只有两端位置，没有速度条件，加速度没有正的必要下界，匀速可连结。

若进一步将207处根速度匹配原207→208的有限差分（F.0613/M.0677m/s），根总轨迹还需要更大的减速界，精确值在JSON；它依赖该边界估计，不是实测人体加速度。原位置轨是线性插值，本身不保证C1；平滑新曲线时必须说明边界速度如何定义。

原源片支持真实前掌蹬地/跳起，但无法验证额外33–36mm根修正是否真实。原投影根205→207只升17.58/19.41mm（按男女目标缩放），平足修正会把根上升加到至少50.22/55.42mm。骨盆不是质心，2D投影/预测3D也没有实测相机和地面；不能凭“跳跃可以快”就将这个约3倍根升高视为合理，亦不能据这些数值断言人体做不到。

## 单姿态足roll几何证明

实际重新查看源204/205/206/207原生足部裁图，保存于ignored `analysis/dance-reference-v1/support-v3-review/source-native-204-207.jpg`。右脚从前掌/鞋缘近地到脚跟抬起再离地，左脚持续摆起，支持heel-rise/toe push-off；206精确离地时刻仍不确定，不能由模糊图硬标接触。原水平足fallback没有表达该变化。

对**原v2的205姿态**做一个静态、只读几何求根：保持root/踝XYZ、腿骨、转体原样，绕踝当前横轴旋转foot/toes，使用实际鞋皮肤权重（小腿影响也保留），求前掌patch最低点Y=0。使用0–60°单一数学根括区，不扫描候选角度/权重，没有导出该角度为动作。

这证明205接地**不必然需要**上述根部快速回升；平足reach下界只适用于平足假设。不同鞋形给不同角度，不能把该角度称为恢复了真人足角。踝XZ不变，但绕踝转动会改变前掌接触位置XZ，未假装no-slip/静止地面锚。

## 唯一可提出的下一候选与止损

1. 沿已有人工事件设节点：已确认支撑区间首尾（含205）、模糊起落区、已确认flight边界。节点描述事件而非每个坏点；206保持未知，不编造准确toe-off。节点处速度待求，不一律设0。
2. 已确认支撑采用明确接触面的高度硬约束：前掌时只前掌贴地、其余鞋不穿地；不要求鞋底全平。由当前几何与原片人工观察定义接触面，标注是人工清理条件，不能包装为检测器产出。原source rootXZ/转体与固定目标骨长保持。
3. 同一个有限约束解中允许rootY、腿IK与脚掌俯仰互相分担，优先最小偏离原root/腿。flight中保护原root/腿/踝轨迹；脚姿可以延续推进过程，但必须非接触。不要先强平足、再用突然的root脉冲补回来。
4. 若要求严格继承全部原flight足旋转，则将角度归零边界明确列为硬条件，报告求解矛盾/速度尖峰并拒收，不能软化支撑门或改标签。点态几何可行不保证有限样条全段同时可行，不能预先承诺输出。
5. 求解后仍须检查实际VRM、121标定、密集插值鞋皮肤，而不只73个原键。v3已经证明键间四元数插值会重新穿地；这是约束离散方式问题，不能靠扩大whole-clip lift遮盖。原始source/男女正常1×对照仍为最终必要检查。

不需要更换视频、新识别模型或产品美术选择才能验证这个有限候选；需要的是明确修正“硬支撑定义”和“水平足fallback”的制作假设。精确足角、摩擦/力、真实全局根深度仍未知，若要声称物理真人重建，则需要新增观测或标定，现有数据不足。本次止于方法判定，没有运行下一候选。
