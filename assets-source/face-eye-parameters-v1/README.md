# 固定眼中心与眼骨的微小眼宽：只读源风险核查

2026-11-15。**可继续一个“眼裂宽度 +1%”的有界源候选研究，不能把整套眼层统一缩放或只缩虹膜当成眼形。** 最小方案是保持虹膜/高光、眼骨pivot和眼裂中心不动，联动Head绑定的眼睑/眼白/眼线/睫毛。现在只有测量和方法，没有改模型、生成端点/recipe、接入runtime或新滑条，也没有Blender/GPU任务。

输入仍是已锁原男女 `base-{female,male}-roundtrip.vrm` 与各自原始编辑blend；完整SHA和原字段在 `measurements.json`，实际重新核对。`source-eye-layers.png` 已查看，显示原眼层、原EYE_Close及骨轴深度；其点包含透明承载几何，未模拟遮挡，不是眨眼视觉验收。图与数据使用原glTF坐标，Y上、-Z前；“+X/-X侧”不凭看图猜左右骨语义，节点映射另行实读。

## 中心和pivot必须分清

“眼中心”在本最小方案明确为原开眼时内外眼角的中点；原虹膜/高光几何中心也保持各自原值，不能把它们偷偷移动到同一点。原眼裂宽女36.594 mm、男37.333 mm。+1%表示总宽增加约0.366/0.373 mm，每眼角向外约0.183/0.187 mm；只是一个待验正端点，不是已通过的±范围。

原Eye pivot并不在可见眼中心：相对眼角中点，女轴心向鼻侧约24.148 mm、后方47.894 mm，男约23.921/50.142 mm；完整local TRS、global rest矩阵和Head矩阵均存数据。虹膜的包围盒中心也比眼角中点向鼻侧偏约女3.489 mm、男3.368 mm。若围绕眼角中点连虹膜一起宽度缩放，哪怕1%，虹膜中心也会漂移约0.035/0.034 mm，已不满足所声明的固定可见中心。

此外非均匀宽度缩放A与眼骨旋转R不交换。用实际原虹膜点和轴心算 `(RA-AR)(v-pivot)`，1%缩放与12°水平诊断旋转的最大不交换量约女0.1238 mm、男0.1248 mm；这是代数反例，非真实游戏轨迹或完整变形误差预测。源lookAt是Bone，horizontal inner/outer输出范围8°/12°、vertical up/down10°。把所有Eye/Head层在静止时拉齐，并不能保证转眼后仍同样对齐。首个候选保持Eye绑定层原几何和rest，可避免引入这类眼层变形，但新眼裂边缘相对于现有注视仍需遮挡验证。

## 全部blink与对应点：已证和不能推定的部分

原VRM blink、blink_l、blink_r分别绑定：女target13/15/14，男11/13/12。三者均逐侧检查：单眼Close只移动同侧眼口，另一侧0；没有复制女性target号到男性。

眼口24点与EyeWhite24点的同坐标配对是强约束：男女两侧共48对，在全部56/54原非Basis形态中最大间隙均为0。因此这些点可以被同一个固定仿射算子驱动，保持原缝。上下眼睑则不是12对12同拓扑：上链12、下链14，最近顶点对应只是候选关系。原完全Close后，上链内部点到下链折线仍有女约1.058 mm、男1.307 mm的最大三维距离；不能把它直接叫“漏眼”——真实遮挡还由皮肤片、眼线/睫毛alpha及深度共同决定，也不能为归零强捏原闭眼曲线。

原Close实际移动多层：女Skin187点、White48、Eyeline254、Eyelash150，睫毛最大位移32.012 mm；女虹膜/高光0点移动。男Skin180、White46、Eyeline222、Eyelash150，睫毛最大28.749 mm；男虹膜/高光各4点有原闭眼修正（最大约0.225/0.250 mm）。**男原虹膜闭眼修正不能删掉**；保留Eye层意味着保留全部原形态，不是把其morph清零。每一原形态的各材质位移、三类Close逐侧边界/配对、单眼效果均在测量中，不能只测全闭眼一帧。

## 唯一最小制作建议（尚未执行）

1. 男女各自从原Basis识别24点眼口环及内外角，固定各侧角中点cx；把它作为眼裂宽度的固定中心。保原Eye bone节点/rest/inverseBind与虹膜/高光全部Basis和绝对shape；不改瞳孔、眼距、眼高、眼球旋转或骨权重。
2. 眼口环、匹配EyeWhite全侧表面、同侧Eyeline/Eyelash使用统一水平系数1.01；Face_SKIN按原边图从眼口环向外8 mm固定衰减至1。当前测得该皮肤邻域女每侧74点、男每侧73点；左右域不交，既有mouth/nose非零mask与非眼口开边均无交集。Eyeline/Eyelash透明图层的可见根部对应必须在源检查和后续带纹理近景中核对，不把此全侧仿射的提案当已证明贴面。
3. 对每个**绝对**shape用同一Basis固定系数：`xNew=cx+(xOriginal-cx)*(1+0.01*w_i)`，Y/Z不变；故相对deltaX也乘该系数，不能照搬鼻/眉的A=I不变delta做法。眼口与EyeWhite配对点须拥有完全相同中心/系数，以代数和导出数据双重保持缝。对所有表情执行，保留原VRM表情名和单眼左右语义。
4. EyeExtra首样件不改，保原特殊效果，不宣称它已随新眼裂适配。FaceBrow、鼻、口、头颈、Body保护；原素材/使用条件和新派生身份单独记录。与当前嘴眉鼻共底组合须在同一不可变原数组上求值，而非累加当前变形。
5. 修改后须按完整Face邻接独立重算Basis和每个绝对shape法线；原VRM是POSITION-only morph，不能把未输出NORMAL当法线自然正确。重复导出/fresh重建、精确身份字段、其他参数reset不被抹掉、每实例隔离仍走已有闭环。

## 无法直接自动适配的机制与停止条件

- **透明眼线/睫毛不是有缝的眼睑拓扑。** 最近点不提供可见根部语义，alpha承载片尾端也不是固定接触点。8 mm皮肤衰减与整片图层仿射可能在外围产生不同位移；需要实际源图层/半闭眼检查，不能靠扩大矩形或统一缩整张脸保证。
- **闭合依赖深度与遮挡，非单一“上下点间距=0”。** 不同采样链与不同透明层不能自动挤成零缝；应比较原态和候选的0/半闭/全闭、左右单眼及原Joy/Angry/Sorrow/Surprised等形态，记录新增露白/露虹膜/层穿插。
- **Head/Eye是不同变换链。** 原注视范围内的内/外/上/下与blink组合必须回读；不能用原骨不变或静态开眼无错宣称注视通过。虹膜/高光保原并不自动保证新的外遮挡层处处安全。
- **端点范围未验证。** 如唯一1%候选出现新增漏眼、睫毛脱离/穿皮、法线跳变或需要改Eye pivot才能补救，停止这个“固定中心/固定pivot”的候选，报告所需假设变化；不继续扫描比例或暗改眼骨。

本轮结论是有可重复的源入口与强缝约束，值得做一次有限候选；并非已经得到眼形样件，也不是获得任意眼型自动适配能力。未写运行时或新控件。
