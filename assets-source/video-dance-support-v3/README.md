## 205失败的具体原因

205来自人工200–205区间：**右脚单支撑、左脚可见摆动**，不是双支撑冲突，也不是把双足腾空误标成支撑。206是模糊起跳边界，207–210是保护的真实双足腾空。

205原右鞋底高36.819/40.611mm；本次右踝仅下降4.136/4.628mm，root仅下降2.228/2.470mm，留下32.691/35.983mm离线悬空。保持当前踝XZ和足朝向，要使右足落地，实际固定腿长的必要界要求root至少下降32.636/36.010mm（未加额外1mm reach裕量），比当前修正仍多约30.4/33.5mm。当前解在reach范围内，并未拉长骨骼。

207必须回到原修正0，距205仅83.42ms。选定有限样条和导数/位移代价、腿reach硬约束，使唯一软支撑优化在此折中并保留残差；**这不证明“真实flight与205支撑在物理上不兼容”**，只证明本固定候选没有同时实现要求。未将205改标腾空，也未牺牲207真实跳跃去压平脚。按10mm支撑门拒收，未调权重/扫节点/增加每帧自由度。
