# 固定两人麦克风接触复验

本组数据来自原签名角色在真实麦架前到位或讲话时的 57 条历史观察，其中浏览器 55 条、固定步长 CPU 模拟 2 条。女体留下 7 条到位退出观察，男体留下 50 条首次到位、持有及关闭重开后的持有观察。各次观察可以来自同一动作。此数据没有女体进入持有后讲话或关闭再恢复的采样。

## 输入与重放

从具备项目锁定依赖的源码目录运行。前两个参数可分别选双房 batch 输出或完整公司交付包。使用 raw batch 时，脚本从其自身源码目录加载对应目录表和 GLB，因此应在与该 batch 匹配的源码版本运行。完整包采用自己的保存、目录表与 GLB，同时核实 viewer 实物文件哈希。第三个参数为新建的证据目录。

```powershell
node scripts/company-platform/check-vocal-fit-contacts.mjs <新双房目录> <vocal-use-v1.1包目录> <新证据目录>
```

对于完整交付包，可从其 source 目录运行相同命令，参数传入候选包与基线包的位置。输出文件为 report.json，其中 baseline 和 candidate 各列双房实物摘要、保存哈希、覆盖网格数量、原装嘴部参考、逐点距离、入射角、朝向角和首个命中物。每房按身体列出最窄的四项余量和它们对应的观察 ID；负余量表示超限。原麦架须复现女 0/7、男 50/50，新麦架须达到女 7/7、男 50/50，每一观察均以网头为首击。把基线包同时当作候选可复现失败，另给一个新的证据目录即可重试。

## 来源与坐标

observations.json 的 sources 列出上游回执路径、SHA-256 及游戏版本，actors 保存原角色 ID、记录签名和身体 SHA-256。samples 每行通过 report、pointer 指回回执内精确字段，通过 actor 和 room 指向身体与设施。该文件 SHA-256 为 `23f87c4d2c1271de4ef4ae69deb6fd8a06d57d94f4f4b59d63de812808e6b762`。

| 来源 | 观察数 | 阶段 |
|---|---:|---|
| 随身唇部定位，两房正常镜头 | 24 | 女体到位退出，男体到位、持有及重开持有 |
| 随身唇部定位，工作室侧镜头 | 7 | 女体到位退出，男体到位及持有 |
| 旧版站唱，两房正常镜头 | 24 | 女体到位退出，男体到位、持有及重开持有 |
| 旧版固定步长 CPU，两房 | 2 | 女体到位退出 |

mouthM、eyeM 和 surfaceM 均来自原回执的世界坐标，先减设施原点，再绕 Y 轴旋转设施 yaw 的负值。坐标单位为米，+Y 向上，+Z 从架体指向歌手。工作室设施位于原点，出租屋设施位于 (−4.5, 0, 0)，旋转 90°。actorYawRad 保留原角色根节点的实测相对 yaw；游戏的平面朝向判定使用站位合同的 yaw。重放前核对使用位、进出点与朝向合同，再将旧采样投进当前房间。

网头瞄准点使用局部几何包围盒中心乘以网头节点的完整变换。报告另列变换后真实顶点包围盒的中心，以便互查。物理收音轴复用公司制作验收从真实握柄后盖面法线的测量。嘴到目标中心的第一交点来自真实房间双面三角网格，包含麦架所有部件、同层其他设施和结构墙。原观察的首击坐标与距离须在 0.002 mm 内重现，两角须在 0.0001° 内重现。保留既有距离 6–26 cm、入射角至多 35° 和平面朝向角至多 45° 的要求。角色负载、连续动作、视觉观感和普通设备性能由游戏实包另外检验。


每条 externalCameraSight 从房中实体桌面相机的真实镜头前表面出发，分别追踪到原观测嘴和眼。57 个上游接触均带有 eyeWorld。只排除作为出发点的镜头表面，机壳、麦架和同层设备仍参与射线，交点与两个视角均按实际安装的相机变换计算。该项描述房内拍摄设备对脸部两点的视线，独立于麦克风距离门。游戏录像另用房间或检查镜头呈现画面；单点视线也无法替代脸部整体或动作过程的可见性检查。
