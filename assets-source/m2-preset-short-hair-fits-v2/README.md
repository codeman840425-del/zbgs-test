Canonical input is `spec.json`; canonical output is `generated/manifest.json`, schema `preset-short-hair-fit-batch-v2`. Its six `results` entries alone define the new fits. Archived attempts are evidence and must not be recursively admitted or published. The two failed lean bodies have no fit.

The existing female bob and male sidepart GLBs are reused byte-for-byte. Original v1 source packages and builders remain unchanged. New source code calls their frame, GLB, dependency, strict-triangle and texture-footprint functions. The new shared auditor measures actual v2 target geometry at every authored endpoint and adds the unchanged original ponytail inclusive intersection test in raw-head-local space. It does not install a generic ignore switch or expand a body-SHA allowlist.

The original absolute-position protection gate refuses all six targets, with changes in six female/eight male Body side-head points. Those strict failures and the original complete measurements remain under `strict-attempt/`. Body source-local ranges are female x ±53.242 mm, y -5.277 to +8.727 mm, z -20.243 to -2.510 mm, and male x ±53.518 mm, y -20.259 to +4.122 mm, z -21.246 to -6.516 mm. Other actually changed Face_SKIN/head-weighted points are also recorded, rather than describing the entire head surface as unchanged.

Root explicitly authorized a new exact-target v2 criterion. Cap indexed positions/normals/UV/joints/weights/triangles, all raw nodes, head/neck/chest inverse binds, original materials and embedded image payloads must match. Actual changed surfaces are then measured at neutral and every original individual morph endpoint. Female source has 56 morphs plus neutral, giving 57 states. Male has 54 plus neutral, giving 55. Every target is freshly computed. All six short-hair fits have zero introduced pairs under both the strict-interior and inclusive tests. Their empty contact-record arrays therefore represent no exception, rather than a claim of verified transparent contact.

Each target folder contains `fit.json`, `manifest.json`, `evidence.json`, `geometry-report.json` and `contact-report.json`. Fit schema is `character-hair-fit-v1`, fit version 2, with original logical style ID and a new exact target SHA. `fit.fitEvidence` contains schema `hair-fit-evidence-v2`, an explicit public URL and SHA. Evidence records the actual target, asset SHA, measured endpoint count, neutral changed vertex IDs/positions, and URL/SHA references to both reports. A publisher must verify and publish that complete referenced chain. Public prefix is `/assets/m2-preset-short-hair-fits-v2/`. The original shared GLB URLs remain unchanged.
