# Desktop computer collection v1

This package contains four project-authored static desktop-computer appearances sharing the `desk-surface` contract and a 0.22 × 0.45 × 0.45 metre envelope. Every GLB has a visible `power-status` node and a visual rear `power` cable endpoint. The package does not claim operating-system behavior, thermal simulation, cable routing or character use.

Build with `node scripts/company-platform/build-desktop-computer-collection.mjs` and run the CPU readback checks with `node scripts/company-platform/qa-desktop-computer.mjs`.
